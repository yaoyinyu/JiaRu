# 2026-09-23 开发日志

## 全项目安全审计（静态 + 依赖 + Git 历史）

对 JiaRu 做了一次只读安全审计，覆盖 `src/`（页面、Route Handlers、`lib/`）、`next.config.ts`、`package.json` 依赖树、`.gitignore`、Git 历史密钥痕迹与 `public/` 暴露面。产出报告 `docs/security-audit-2026-09-23.md`。

**关键结论：**

- **严重 1 项**：`next@16.2.9` 命中 CVE-2026-75604（GHSA-p293-qw3h-jr36）Windows 主机未授权 RCE，CVSS 9.0，官方声明无缓解方案，修复版本 16.3.3（npm 建议 16.3.6）。本项目正是 Windows + App Router 部署且经 cloudflared 暴露公网，属直接受影响配置。同一版本还涵盖 8 条 Next.js 公告（SSRF、缓存混淆、AVIF RCE、内部端点泄露等）。
- **高危 3 项**：生产认证链路实际不可用且 dev 模式验证码经 `devCode` 明文回传；全站缺失 CSP / X-Frame-Options / nosniff / HSTS；三处 500 分支把内部异常原文回显客户端。
- **中危 5 项**：无 IP 级限流（短信与 captcha 可刷）；refresh token 30 天静态无轮换与重放检测；无显式 CSRF Origin 校验；`bindPhone` 可枚举已注册手机号；付费 AI 接口游客身份取自可伪造的 XFF。
- **低危 4 项**：审计 IP 信任 XFF；ar-demo iframe 无 sandbox；JWT 未校验 iss/aud；captcha Map 无条数上限。

**确认安全的部分**（无需改动）：`db.ts` 全参数化无 SQL 注入；全仓无硬编码密钥；`.env.local` 从未被 Git 跟踪；无 `dangerouslySetInnerHTML`/`eval`；AI 客户端强制 HTTPS 且校验返回 URL；摄像头流完整释放；上传校验完整；无第三方 CDN 外链。

**本轮未产生任何代码、配置或接口变更**，因此技术白皮书 §13 无需新增变更记录条目，文档版本不顺延。待执行 C1（Next.js 升级）等修复时再按规则同步白皮书与版本号。
