# 甲如消费者端重设计提案

> 2026-10-21 · 视觉方向已获认可，终端适配与浏览器验收继续完善；独立原型尚未切换旧版。
> 当前能力状态以技术白皮书 §3、§4.7、§10 为准。

## 1. 已确认的产品方向

- 消费者与美甲师分别设计；本阶段只交付消费者设计提案，美甲师端保留独立产品空间。
- 手机和平板优先，同时适配宽屏桌面；按屏幕、输入方式与浏览器能力调整，不依赖操作系统名称猜测布局。
- 目标用户以爱美女性为主：用有辨识度的审美、清楚的内容来源、真实的能力说明建立信任。
- 克制、稳重、亲近且有活力；米白、深墨、低饱和珊瑚。消费者简单易用，商家专业可靠。
- 后续遵循“设计不一定是加法”：减少重复文案与装饰，用图片、图形、字体层次和留白表达；关键能力与数据边界保持可查。
- 四个主入口：为你／试戴／创作／我的。精选素材为主、AI 补充、登录用户可上传发布。
- 先了解偏好，可跳过；再推荐、试戴或创作、收藏保存、分享给美甲师。
- 基础社区首版含个人主页、发布、点赞、收藏、关注；评论、私信、预约与交易不纳入首版。

## 2. 视觉方向与主视觉

设计主题：**指尖的日常美学**。首页像一本轻盈的美妆手册，工具页像可以放心使用的小工作室。

| 要素 | 当前提案 | 用途 |
| --- | --- | --- |
| 米白 `#F7F4EE` | 大面积背景 | 留白、温度与长时间阅读 |
| 深墨 `#292A27` | 标题、文字、主按钮 | 清晰、稳定的视觉锚点 |
| 珊瑚 `#AC5145` | 状态、细节与重点 | 少量活力，避免大面积抢占美甲色彩 |
| 灰绿 `#E3E7DD` | 次级内容底色 | 作为暖调主色的安静补充 |
| 手写感品牌字、本地衬线标题与清晰中文正文 | 品牌／标题／正文分层 | 建立个性与阅读节奏 |
| 大图、圆角与细分割线 | 手部主视觉／内容结构 | 图片承担审美，控件承担操作 |

参考图：`辅助材料/e6430208ec92f5074dddeef16b71e9de.jpg`，完整图 SHA-256 `a1095e510bdd9cec0811ec7911a27722318f333fd1905d68c91edd91126f823e`。仅借鉴奶油底、手写感、手部大图、明确深色主按钮与五指照片贴图的构图，不复制其品牌、设备外框或截图控件，不把它当作可直接发布的产品资产。

用户追加的首页要求：**纤细白皙的手背，五指覆盖不同甲型、长短、材质、色彩与设计的美甲贴图**。当前主视觉为 `design/consumer-v1/assets/hero-hand-diversity-v3.png`：短圆冰透／长梯形酒红猫眼／椭圆贝母／尖杏仁淡紫碎钻／短方圆蓝色几何。贴图保留矩形照片边缘和对应指向。

主视觉为 AI 生成的设计素材，不是实际试戴或模型质量证据，也不进入训练或数据集角色体系。v1 纯法式与 v2 五色贴图保留作本地设计比较。生成提示见 `design/consumer-v1/assets/prompts.md`。

本轮精简首页介绍、重复说明和次级口号，以图形化的照片／摄像头入口、收藏按钮与导航状态表达动作。能力说明收进可展开的“使用说明”，检查工具收进“预览设置”，页脚保留“关于预览”入口；AI 素材和非本次生成的标识继续常显。

中文标题采用同源加载的 Noto Serif SC 衍生 WOFF2 子集，259,272字节，保留400–600字重轴、723个码位，其中614个汉字；按 SIL Open Font License 1.1 随附许可，内部家族已重命名。`font-display: swap` 和系统后备使字体未加载时仍可阅读操作；正文与用户自由输入保留系统字体。它不是完整中文字库，新增标题须检查字形覆盖。来源、许可与后备说明见 `design/consumer-v1/assets/fonts/README.md`，机器记录见本地 `output/frontend-redesign-v2/font-verification.json`。页面不访问远程字体 CDN。

### 2.1 终端布局、操作与轻动效

| 场景 | 当前实现 | 验收边界 |
| --- | --- | --- |
| 窄屏手机 | 底部四入口、单列操作区、紧凑图形试戴卡；主要图标触控区域至少44 CSS px | 390×844与320×740最终截图已复核；独立Pixel 7触控模拟的图形、文字、箭头tap均进入对应流程 |
| 平板与横屏 | 按可用宽度双列或单列；短横屏精简页头和试戴页重复介绍，使用120px高并排横卡 | 390竖屏及844／600×390短横屏两张试戴卡均位于底栏上方；模拟检查不替代真机安全区 |
| Windows等宽屏终端 | 顶部导航、并排内容区、受控最大宽度；细指针支持悬停反馈 | Windows Edge完成键盘、字体、图标及12组布局检查；悬停不承担唯一操作入口 |
| iOS／Android浏览器输入 | 安全区覆盖四边；输入框16px；根据视觉视口和当前编辑控件识别软键盘，输入时收起底栏 | 保留用户缩放；双指缩放不应被视为键盘。系统键盘、安全区及真机仍待验证 |
| 键盘与辅助操作 | 可见焦点、跳到主体、原生dialog与Esc／遮罩关闭、关闭后返回原页触发点、浏览器返回恢复滚动位置 | 跳过链接不改路由；跨页关闭不把焦点移到新页同名按钮；快速重开不被旧close事件解锁；同页重绘保留文本选择 |

动效围绕反馈与空间连续性：页面短距离淡入、卡片进入视口、按钮轻压与收藏状态回应、底栏显隐和弹层过渡。没有为展示动效增加必经步骤；快速切页会取消旧页面动画。基础 Web Animations、IntersectionObserver、VisualViewport 缺失时保留直接可操作界面，不依赖 View Transition API。开启系统“减少动态效果”时取消现有脚本动画，后续操作不再启用位移动画，CSS过渡同步减弱。

触控模拟同时确认粗指针、无悬停、`maxTouchPoints>0`与实际tap，区别于只缩小桌面视口或派发pointer事件。减少动态效果检查包含加载圆环CSS旋转、弹层位移与运行时停止动画；这仍是浏览器设置模拟，不代表已在各系统真机切换设置验收。

## 3. 页面结构与关键流程

| 页面 | 内容与主要动作 | 返回与异常 |
| --- | --- | --- |
| 为你 | 品牌主视觉、了解偏好、款式搜索与分类、详情、收藏 | 无结果时引导换词或创作；实际推荐服务未接入 |
| 初次引导 | 风格与自由描述 → 场景与长度 → 可选照片 → 可编辑摘要 | 每步可退出；返回保留本次选择；无照片也可完成 |
| 试戴 | 先选照片或摄像头，可切换为他人使用 | 始终保留另一方式入口 |
| 照片模式 | 本次手图、已选款式、补充要求、AI 参考结果与方案 | 上传错误、等待、失败、保留输入重试；原型只用样图演示结果布局 |
| 摄像头模式 | 拍摄指导、开启流程、选色位置 | 权限拒绝、无设备、加载、无手等流程需正式实现；原型不申请权限 |
| 创作 | 快捷灵感词、自由描述、可选参考图、次级设置与结果 | 本次跨页保留草稿；错误可重试，不伪造生成 |
| 我的 | 偏好、收藏、作品入口、关注、保存范围 | 游客也可浏览；模拟登录与真实登录严格区分 |
| 款式详情／创作者主页 | 来源、标签、推荐理由位置、点赞、收藏、关注、试戴 | 演示账号与 AI 素材常显，无伪造人气数字 |
| 发布／我的主页 | 图片、名称、说明、来源与分享确认 | 先登录；原型仅生成内存中的发布预览，刷新不保留照片，不公开 |
| 美甲方案卡 | 已选款式、长度、场景、补充需求 | 可保存 PNG／复制文字；支持时主动调用系统分享；返回原照片或创作流程，样图不冒充用户上手效果 |

原型支持浏览器返回、前进和列表滚动恢复；页面底部展开“预览设置”后可切换线框视图，并检查失败、空内容和数据边界。搜索只更新结果区域，中文合成输入保留原控件；异步生成完成也避免打断正在合成的文本。

## 4. 偏好、照片与他人体验

- 显式偏好、长期行为、本次场景、手部特点分开保存；手部特点在消费者端权重较低，不预设未经验证的数值权重。
- 正式版由语言模型结合用户标签、收藏与照片提取特点，生成简短可纠正的描述。自动学习要避免把单次特殊场景改写为长期审美；具体聚合和撤销设计在服务验证后确认。
- “为身边的人试戴”沿用账号审美，只替换本次手图，不覆盖主人手图、特点与长期档案。
- 手部原照片默认本地；用户已允许将照片发送给视觉模型分析。这是按需处理，不等于默认云端长期保存照片。第三方留存条款须按实际服务核对，不承诺供应商必然不存储。
- 特点关键词、偏好和作品是跨设备方向。作品公开发布属于另一项主动公开行为；发布前需说明实际公开内容，不能把本地手图直接随档案上传。
- 游客先本地使用，登录后再设计去重与合并；当前 IndexedDB 收录和账号系统不能直接视为已完成云同步。
- 原型只有独立 `jiaru-consumer-design-v1` localStorage：保存偏好模板、收藏、喜欢、关注与相关选项。照片仅使用内存对象 URL；刷新需重选，不保存照片像素或“已提取特点”。
- 照片试戴与创作分别保存会话描述、等待／结果状态及选款，不因切页串用。发布选图不取消照片试戴任务；换图采用顺序标记，避免旧解码结果覆盖新选择。
- 偏好描述、引导摘要及学习开关的未保存草稿可跨页继续，显式保存后才更新长期偏好；发布标题、说明、来源与权利选择在模拟登录前后保留。会话草稿不代表刷新后恢复或云同步。
- 当前原型没有任何模型、API、上传或真实用户认证请求；模拟登录不持久化，也不创建账号。
- 方案图片在页面内预先编码，缓存按款式、长度、场景、来源流程与描述区分；仅当前方案准备好后启用分享。用户主动点击后先检测文件分享能力，不支持或调用异常时提供PNG保存；取消分享不提示失败，也不宣称已发送成功。分享内容是标注AI示例的方案卡，不附原手图、本机预览链接或账号数据。系统分享在自动检查中使用替身，未向外部接收方发送文件。

## 6. 独立预览、备份与切换

运行 `node scripts/serve-consumer-design.mjs`，访问 `http://127.0.0.1:4318`。不放入 Next.js 正式路由，不导入旧版 CSS，不读取 `.env.local` 或真实账户数据库。服务只绑定本机，按白名单提供原型、图片与本地字体；字体许可随源码保存在字体目录。不支持写请求，浏览器 CSP 禁止网络连接，摄像头权限被禁用。系统分享仅由主动点击触发，不等于原型主动上传数据。

旧版在变更前按当前磁盘保存至 `.backup-consumer-20261020-v1/frontend-current.zip`，包含当时未提交修改。清单 `manifest.json` 绑定716文件的大小与 SHA-256，压缩包 SHA-256 为 `9815c519eb7f11108b14d13ee218cffa7e2e4e635afb59f04f1a67ffb42cac98`。不包含真实密钥、真实用户库、训练目录和训练权重；`public` 下运行时资产按原字节保留。

恢复方法：先验压缩包 SHA，再解压至新的隔离目录，按清单逐文件验真；依赖可复用本机已安装版本，本轮没有重新验证联网 `npm ci`。真实配置与用户数据库需按原运营备份单独恢复，不能从该前端包推断完整业务数据备份。不得覆盖当前工作区。

上一阶段恢复验证：逐文件解压验真通过；恢复目录独立启动 `next dev --webpack` 后 `/`、`/gallery`、`/editor`、`/privacy` 均返回200。生产构建未通过：Webpack暴露原识别调试模块的 `node:crypto`／`node:path` 浏览器导入；Turbopack在沙箱和宿主均遇到CSS子进程提前退出。失败保留在 `restore-validation.json`，不宣称整个旧版生产构建已恢复验证。

本轮精进前另保存已认可设计的当前磁盘快照：`.backup-consumer-refinement-20261020-v1/approved-preview.zip`，7,005,471字节，SHA-256 `f3f2746d32112f4abf5ec7d3eab790ab65d487e85b369de941d6189a64e28b25`。其 `manifest.json` 绑定12个文件，包含当时原型、图片、服务脚本与对应文档；`zipReadbackPassed=true`，压缩包读取验证通过。它用于恢复精进前的设计，不取代完整旧版前端备份，也不构成新的生产构建验收。

切换必须在视觉、交互、服务选型及对应功能验收后另行确认；本轮不切换、不部署、不提交推送。未来正式接入新增偏好／行为／手部特点／作品／关注等契约时，应以独立服务边界实现，再定义鉴权、合并与版本；原型的本地结构不是生产 API 合同。

## 7. 提案评审与验收

- 手机、平板、横屏与桌面检查：320×740、390×844、844×390、768×1024、1024×768、1440×1000 CSS px；同时检查触控、鼠标、键盘和减少动态效果分支。
- 检查首次引导可跳过、无照片可完成、摘要可纠正；换页回退保留会话草稿。
- 他人照片不得覆盖本人照片；本地与云端文案一致；原型不外发图像。
- 收藏与取消收藏、无结果／无收藏、模拟登录后本地发布、关注状态、详情到试戴和方案路径应可操作。
- 生成等待、失败重试与返回输入要可见；样图必须始终注明非本次生成，不能声称已有上手效果。
- PNG方案卡可实际保存且包含示例标识；系统分享须保留下载／复制降级、取消语义与用户主动触发，不自动发布、发消息或伪造社区互动。

### 8.4 有意的风格偏差（已登记）

1. 基底用品牌米白 `#f7f4ee` 而非规范 `#e0e5ec`/`#f0f0f3`，阴影色同步换为暖灰／暖白——保持品牌色彩（用户明确要求）；
2. 强调色用品牌珊瑚／深墨而非规范 `#6d5dfc`；
3. 墨底元素（主按钮、toast、偏好引用卡）用环境投影或墨底内凹，不套表面双光源；
4. 控件保留全圆胶囊（品牌圆角语言），卡片／托盘统一 16–24px；
5. 文本列表保留 1px 细分割线（规范只禁 `border-2+`）；
6. 编辑式 eyebrow、hero 手写字等品牌编辑语言保留；
7. 功能性横滑渐隐 mask 与线框诊断态（灰度＋灰描边）保留；
8. 键盘焦点保留 2px 珊瑚焦点环（WCAG 2.1 AA 要求，规范示例的 `outline-none` 不采用）；
9. 输入 focus 方向取「内阴影减小」：规范 [REQUIRED] 示例（4→6 加深）与其「必须遵守」及交互状态表（6→2 减小）自相矛盾，按光照物理（通道开放）与多数条款执行减小。
10. 2026-10-23 动效方案 §2.1/§2.2 的按压缩放与滑块挤压反弹（`scale(.96)`→过冲→落位）：与上面移除的「位移悬停」不冲突——全程只有原地缩放/挤压，平移分量恒为 0、布局不位移；逐条偏差登记见 `docs/consumer-redesign-motion-plan.md` §1。

- 问题根因：`border-radius: 50%` 在**非正方形**元素上按两轴分别取 50%——52×30 轨道得到 26×15 的四分之一椭圆角，两角椭圆横向占满整宽（26+26=52），中段没有任何直线，整体呈纺锤形椭圆。正方形元素（44×44 图标钮等）用 50% 是正确的圆，不受影响。
- **统一参数**：新增 Token `--radius-capsule: 999px`（"大于半高即钳制为半高"的尺寸无关写法，对固定控件亦可写精确半高值）。胶囊＝两端标准半圆（半径=高/2）＋中段平行直线；判定式 `border-radius ≥ height / 2`。
- **宽度比例**（以拨动开关轨道为基准实例）：

| 参数 | 值 | 关系 |
| --- | --- | --- |
| 轨道宽×高 | 52×30 | 宽高比 ≈ 1.73:1（建议 1.5:1–2:1，保证中段有可见直线） |
| 圆角（生效） | 15px | ＝ 高/2；CSS 写 `var(--radius-capsule)`（999px 钳制） |
| 中段直线长 | 22px | ＝ 宽 − 2×圆角 ＝ 52 − 30 |
| 滑块 | 24px 圆 | ＝ 高 − 2×3px 内偏距；行程 22px ＝ 宽 − 高 |
| 通用约束 | 宽 ≥ 2×高 | 滑块类轨道推荐「宽 ＝ 高 ＋ 行程」 |

- **统一应用范围**（本次同批切换为 `var(--radius-capsule)`，除两处椭圆修复外视觉零变化——原固定 px 值均≥半高，钳制后生效半径相同）：`.switch-row::before`（开关轨道，椭圆→胶囊，主修复）、`.icon-action`（带文字的功能按钮如页脚「关于预览」95×44，椭圆→胶囊，同类修复）、`.primary/.secondary/.text-button`（原 30px→半高 24）、`.chip`（原 30px→22）、`.desktop-links a`（原 22px，本就=半高）、`.tag-option span`（原 24px→22）、`.search-box`（原 30px→24）、`.mode-illustration::before` 编号 chip（原 20px→半高）。**保持 `50%` 不动的**：全部正方形圆形控件（`.round-button`/`.save-button`/`.callout-mark`/`.avatar`/开关滑块/模式卡圆形 CTA 等）及拱形/异形圆角（`.mode-illustration`、`.detail-image`、`.preference-card` 签名角、`.onboard-photo`）。
- **效果说明**：两端为标准半圆、中段直线平行等宽，轮廓匀称不失真；与新拟态双光源阴影配合时凹槽高光/暗部沿直线段平行走向，滑块吸附定位的起止更清晰；与品牌既有胶囊语言（主/次按钮、chip、导航胶囊、搜索框）完全同构，消除"椭圆 vs 胶囊"混搭；小高度控件（如编号 chip）自动收敛为半圆端，无需按控件逐个试值。
- 验证：复选框套件新增 C10a/C10b/C10c（token 定义、轨道胶囊参数、icon-action 非正方形胶囊化）；七套回归合计 **223 项断言全部通过**（新拟态 80、修复 45、导航 17、复选框 25、动效 12、试戴 14、间距 30）；导航套件 N1e 同步改为 token 口径（44px 高→生效 22px，视觉不变）；截图 `output/design-review-shots/v9-capsule-*.png`（开关 on/off 特写、icon-action、首页）原像素复核：椭圆已消除、既有胶囊控件无视觉变化。

### 8.9 动效方案落地与浏览器级验收（2026-10-23）

- 规格来源：`docs/consumer-redesign-motion-plan.md` §2.1–§2.11（11 项）。本轮在 `design/consumer-v1/style.css`、`app.mjs` 内落地，不改路由、本地存储键、预览服务边界与数据隔离口径。
- 实现要点（按规格序号）：
  1. §2.1 按压：`.is-pressed` 140ms 下沉 `scale(.96)`；释放 340ms `cubic-bezier(.34,1.56,.64,1)` 三段帧 `.96→1.026→1`（实测峰值 1.023、随后 0.995 压回再落位）；重新按下会取消未完成回弹，键盘 Enter/Space 同参。
  2. §2.2 开关滑块：真实元件 `span.switch-knob`；`@property` 注册 `--knob-x/--knob-sx/--knob-sy`，位移与挤压分别过渡；起步 `scale(1.24, .88)` 120ms → `is-settling` `(.97,1.03)` → 落位 1:1，行程 22px（左 3px → 25px）；阴影 token 全程不变，下方卡片零位移。
  3. §2.3 水波：原点＝指针落点（±1px），半径＝到最远角距离 ×1.02，480ms 扩散；键盘触发（click `detail===0`）在控件中心补水波；局部重渲染后按原坐标在新元件补发。
  4. §2.4 爆散：轻档 9 粒／中档 13 粒（固定种子 `window.__jiaruMotionRandom`），只用于可验证成功（收藏、生成就绪、导出、发布完成），失败不爆散；覆盖层在最后一粒结束时移除，同一控件 250ms 节流。
  5. §2.5 勾选：`pathLength=100` 的 `stroke-dasharray/offset` 280ms 逐笔绘制；对钩常驻 DOM 占位，选中前后标签宽度不变。
  6. §2.6 液态滑杆：`@property --v` 单时间轴 400ms；填充宽度、滑钮位置、液面隆起（`is-adjusting` `scaleY(1.18)`）同频；松手吸附 5 档，方向键/Home/End 可用。
  7. §2.7 数字滚动：每位 `0–9` 列 `translateY(-1.2em)`；时长 `320 + (位数-1)×100` ms、延迟 `(位数-1)×80` ms、强减速 `cubic-bezier(.16,.84,.34,1)`；统计区与滑杆数值共用；`|差值|>5` 或位数变化直接落位，不滚动。
  8. §2.8 骨架落位：骨架与真实内容同模板同 spacing，`is-swapping` 网格同格堆叠，骨架 180ms 淡出后移除；实测骨架/内容/面板高度差均在 1px 内。
  9. §2.9 翻面：`perspective:1100px` + `preserve-3d` + 双面 `backface-visibility:hidden`，520ms 到 `rotateY(180deg)`，可中断反向。
  10. §2.10 汉堡：单个 `.morph-toggle` 内三条 `.morph-line`，`aria-expanded` 驱动；中线 180ms 收起、上下线延后 40ms 旋转 ±45°，按钮本体零位移、无第二图标闪切。
  11. §2.11 堆叠卡：三张 `data-depth` 卡按 12px/4.5% 递进；抽走时后卡同帧前移（实测上移 15.2px），340ms 飞出后移出 DOM，`放回最上面` 320ms 归位。
- 降级（`prefers-reduced-motion: reduce`）：脚本水波、爆散、回弹、滑块编舞、液面隆起全部跳过；勾选与弹层显隐瞬时到位；统计与滑杆数字直接写字、不建列；翻面改为静态换面；按压无缩放。
- 本轮修复的缺陷：堆叠卡「放回最上面」在抽走动画 340ms 结束后失效（根因：`flyOut` 在 `onfinish` 里把 `removed` 清空，而撤销处理器以 `removed` 作唯一前置条件，导致按钮可见但点击无效）。改为 `flying`（动画进行中）与 `removed`（已抽走、可恢复）双状态：动画结束只清 `flying`，撤销后清 `removed`，拖拽/再次抽走以 `flying` 判忙；复验抽走 2 张→撤销恢复 3 张、层级回到 0/1/2。
- 验证（本地，不入库）：新增 `output/design-motion-verify.mjs`，**93 项断言全部通过**——11 项规格逐条机器断言（含 `getAnimations` 读取 CSSTransition 属性/时长/曲线、rAF 采样回弹峰值、骨架/面板高度契约、3D 矩阵与 `backface-visibility`）、16 条路由回归、reduced-motion 独立上下文 9 项；七套既有回归串行复跑合计 **224 项**（新拟态 81、修复 45、导航 17、复选框 25、动效 12、试戴 14、间距 30），无 pageerror/console error。截图 `output/design-review-shots/v11-motion-{switch,check,skeleton,liquid,flip,morph,stack}.png`。
- 三处旧断言按新设计口径更新（均注明原因，非放宽门）：N2m 由「过渡声明不含 transform」改为运行时「静止/悬停平移分量为 0」并新增 N2m2「按压只有缩放、无平移」；F10a 由文本比对改为按 `digit-column` 偏移还原数字；复选框套件 `::after` 读法改为真实元件 `.switch-knob`，C8t 过渡属性由 `transform` 改为 `--knob-x`，C9 同样改读该元件。
- 影响范围：仅原型动效与堆叠卡撤销逻辑；未切换、未部署、未执行 git 提交；真机（Android/iOS、WebKit、真实键盘/安全区、原生分享）验收边界不变。

### 8.10 喜欢/收藏改为就地更新与统一反馈（2026-10-23）

- 现象（用户）：点击喜欢/收藏后页面局部像被刷新，反馈一闪而过、几乎看不见。
- 根因定位（源码事实，非推测）：`save`/`like` 处理器先改状态再调用整页 `render()`（`#app.innerHTML` 全量重建）并 `window.scrollTo` 回填滚动位；重建后通过 `respawnRipple` 手动补偿水波、再对新节点播 260ms 脉冲。于是：①整块 `.page-view` 与页头、卡片、`<img>` 全部重建，视口内出现闪一下的重绘；②`revealCards()`/`upgradeStats()` 随重建重跑，卡片入场与数字列重置；③焦点与滚动位置被动重置；④补偿用的脉冲在用户已经"看到页面变了"之后才播放，主观感受是反馈缺失。全程**无任何网络请求**（`persist()` 仅同步写 `localStorage`，CSP `connect-src 'none'`），所谓"刷新"纯属客户端重渲染。
- 一致性问题（同批修正）：同一动作三种写法——卡片图标钮有 `is-saved`＋`aria-pressed`，详情页文字钮只有文案、没有状态类（`.secondary.is-saved` 样式从未生效），示例结果钮既无状态类也无 `aria-pressed`。
- 方案：新增 `paintReaction / pulseReaction / syncStatCounter / pruneSavedCard` 四个局部更新函数，处理器不再调用 `render()`：
  1. **只改被点控件**：`[data-action][data-id]` 就地设置 `aria-pressed` 与 `is-saved`/`is-liked`，文字钮只改 `.reaction-label` 文本（`data-label-on/off` 承载文案），图标钮同步 `aria-label`；
  2. **统一选中态**：图标钮＝珊瑚底＋`#fffdfa` 实心图标；文字钮＝珊瑚字＋珊瑚柔底＋内凹阴影；实心度 `fill-opacity .2`；桌面/移动同一套；
  3. **可感知但不拖沓**：340ms 回弹脉冲 `scale(当前)→1.09→.985→1`（`cubic-bezier(.34,1.56,.64,1)`），连点时取消并重启而非叠加；保留轻档 9 粒爆散；
  4. **明确提示**：`已收藏「款式」`/`已取消收藏「款式」`/`已喜欢「款式」`/`已取消喜欢「款式」`，复用既有 toast（role=status，4.4s，移动端位于底栏之上）；
  5. **失败回滚**：`persist()` 返回成功与否，失败时回滚内存与界面并提示「收藏未保存：本地预览存储不可用，本次改动已回滚」；
  6. **计数与列表**：同页存在统计数字时就地滚动更新（不重建统计区）；收藏页取消收藏只收起该卡（220ms 淡出），清空后局部换成空态。
- 边界覆盖：快速连点（5/10 次）状态以内存为准、脉冲不叠加、提示取最后一次；取消再点；存储被禁用（`Storage.prototype.setItem` 抛错）时回滚；刷新后由 `localStorage` 恢复选中态；移动端 `tap`（390×844）与桌面同一套状态、时长与配色，提示可见且在底栏之上；`prefers-reduced-motion` 下无脉冲与爆散，仅颜色/文案变化。
- 验证（本地，不入库）：新增 `output/design-reaction-verify.mjs` **49/49 PASS**——同一按钮/DOM 复用（零区块移除）、滚动位置不变、零 fetch/xhr、选中态与配色/实心度、脉冲时长、提示文案、爆散 9 粒、同页统计就地滚动、详情页喜欢与收藏同构、收藏页剪枝与空态、连点与取消再点、存储失败回滚、刷新恢复、移动端一致、reduced-motion 降级；八套既有回归合计 **317 项全部通过**（动效 93、新拟态 81、修复 45、导航 17、复选框 25、动效基线 12、试戴 14、间距 30），全程无 pageerror/console error。截图 `output/design-review-shots/v12-reaction-{saved,like,saved-empty,mobile}.png`。
- 影响范围：仅喜欢/收藏交互与相应模板结构（新增 `.reaction-label`、`data-reaction-name`、`data-label-on/off`）；未改路由、存储键、数据隔离与预览服务；未切换、未部署、未执行 git 提交；真机验收边界不变。
