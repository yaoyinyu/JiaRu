# 甲如消费者端重设计提案

> 2026-10-20 · 视觉方向已获认可，继续精进独立可交互原型；尚未切换旧版。
> 当前能力状态以技术白皮书 §3、§4.7、§10 为准。

## 1. 已确认的产品方向

- 消费者与美甲师分别设计；本阶段只交付消费者设计提案，美甲师端保留独立产品空间。
- 手机和平板优先，同时适配宽屏桌面；按屏幕、输入方式与浏览器能力调整，不依赖操作系统名称猜测布局。
- 目标用户以爱美女性为主：用有辨识度的审美、清楚的内容来源、真实的能力说明建立信任。
- 克制、稳重、亲近且有活力；米白、深墨、低饱和珊瑚。消费者简单易用，商家专业可靠。
- 后续遵循“设计不一定是加法”：减少重复文案与装饰，用图片、图形、字体层次和留白表达；关键能力与数据边界保持可查。
- 四个主入口：为你／试戴／创作／我的。精选素材为主、AI 补充、登录用户可上传发布。
- 先了解偏好，可跳过；再推荐、试戴或创作、收藏保存、分享给美甲师。
- 基础社区首版含个人主页、发布、点赞、收藏、关注；评论、私信、预约与交易不纳入首版。

## 2. 视觉方向与主视觉

设计主题：**指尖的日常美学**。首页像一本轻盈的美妆手册，工具页像可以放心使用的小工作室。

| 要素 | 当前提案 | 用途 |
| --- | --- | --- |
| 米白 `#F7F4EE` | 大面积背景 | 留白、温度与长时间阅读 |
| 深墨 `#292A27` | 标题、文字、主按钮 | 清晰、稳定的视觉锚点 |
| 珊瑚 `#AC5145` | 状态、细节与重点 | 少量活力，避免大面积抢占美甲色彩 |
| 灰绿 `#E3E7DD` | 次级内容底色 | 作为暖调主色的安静补充 |
| 手写感品牌字、本地衬线标题与清晰中文正文 | 品牌／标题／正文分层 | 建立个性与阅读节奏 |
| 大图、圆角与细分割线 | 手部主视觉／内容结构 | 图片承担审美，控件承担操作 |

参考图：`辅助材料/e6430208ec92f5074dddeef16b71e9de.jpg`，完整图 SHA-256 `a1095e510bdd9cec0811ec7911a27722318f333fd1905d68c91edd91126f823e`。仅借鉴奶油底、手写感、手部大图、明确深色主按钮与五指照片贴图的构图，不复制其品牌、设备外框或截图控件，不把它当作可直接发布的产品资产。

用户追加的首页要求：**纤细白皙的手背，五指覆盖不同甲型、长短、材质、色彩与设计的美甲贴图**。当前主视觉为 `design/consumer-v1/assets/hero-hand-diversity-v3.png`：短圆冰透／长梯形酒红猫眼／椭圆贝母／尖杏仁淡紫碎钻／短方圆蓝色几何。贴图保留矩形照片边缘和对应指向。

主视觉为 AI 生成的设计素材，不是实际试戴或模型质量证据，也不进入训练或数据集角色体系。v1 纯法式与 v2 五色贴图保留作本地设计比较。生成提示见 `design/consumer-v1/assets/prompts.md`。

本轮精简首页介绍、重复说明和次级口号，以图形化的照片／摄像头入口、收藏按钮与导航状态表达动作。能力说明收进可展开的“使用说明”，检查工具收进“预览设置”，页脚保留“关于预览”入口；AI 素材和非本次生成的标识继续常显。

中文标题采用同源加载的 Noto Serif SC 衍生 WOFF2 子集，259,272字节，保留400–600字重轴、723个码位，其中614个汉字；按 SIL Open Font License 1.1 随附许可，内部家族已重命名。`font-display: swap` 和系统后备使字体未加载时仍可阅读操作；正文与用户自由输入保留系统字体。它不是完整中文字库，新增标题须检查字形覆盖。来源、许可与后备说明见 `design/consumer-v1/assets/fonts/README.md`，机器记录见本地 `output/frontend-redesign-v2/font-verification.json`。页面不访问远程字体 CDN。

### 2.1 终端布局、操作与轻动效

| 场景 | 当前实现 | 验收边界 |
| --- | --- | --- |
| 窄屏手机 | 底部四入口、单列操作区、紧凑图形试戴卡；主要图标触控区域至少44 CSS px | 包含320px回退规则；最终紧凑卡仍待浏览器截图复验 |
| 平板与横屏 | 按可用宽度双列或单列；短横屏压缩导航高度，内容仍可滚动 | 不通过固定设备型号锁定方向或尺寸 |
| Windows等宽屏终端 | 顶部导航、并排内容区、受控最大宽度；细指针支持悬停反馈 | 鼠标、触控与键盘可切换，悬停不承担唯一操作入口 |
| iOS／Android浏览器输入 | 安全区覆盖四边；输入框16px；根据视觉视口和当前编辑控件识别软键盘，输入时收起底栏 | 保留用户缩放；双指缩放不应被视为键盘。系统键盘、安全区及真机仍待验证 |
| 键盘与辅助操作 | 可见焦点、跳到主体、原生dialog与Esc／遮罩关闭、关闭后返回触发点、浏览器返回恢复滚动位置 | 跳过链接不改页面路由；同页重绘保留操作焦点和文本选择 |

动效围绕反馈与空间连续性：页面短距离淡入、卡片进入视口、按钮轻压与收藏状态回应、底栏显隐和弹层过渡。没有为展示动效增加必经步骤；快速切页会取消旧页面动画。基础 Web Animations、IntersectionObserver、VisualViewport 缺失时保留直接可操作界面，不依赖 View Transition API。开启系统“减少动态效果”时取消现有脚本动画，后续操作不再启用位移动画，CSS过渡同步减弱。

## 3. 页面结构与关键流程

| 页面 | 内容与主要动作 | 返回与异常 |
| --- | --- | --- |
| 为你 | 品牌主视觉、了解偏好、款式搜索与分类、详情、收藏 | 无结果时引导换词或创作；实际推荐服务未接入 |
| 初次引导 | 风格与自由描述 → 场景与长度 → 可选照片 → 可编辑摘要 | 每步可退出；返回保留本次选择；无照片也可完成 |
| 试戴 | 先选照片或摄像头，可切换为他人使用 | 始终保留另一方式入口 |
| 照片模式 | 本次手图、已选款式、补充要求、AI 参考结果与方案 | 上传错误、等待、失败、保留输入重试；原型只用样图演示结果布局 |
| 摄像头模式 | 拍摄指导、开启流程、选色位置 | 权限拒绝、无设备、加载、无手等流程需正式实现；原型不申请权限 |
| 创作 | 快捷灵感词、自由描述、可选参考图、次级设置与结果 | 本次跨页保留草稿；错误可重试，不伪造生成 |
| 我的 | 偏好、收藏、作品入口、关注、保存范围 | 游客也可浏览；模拟登录与真实登录严格区分 |
| 款式详情／创作者主页 | 来源、标签、推荐理由位置、点赞、收藏、关注、试戴 | 演示账号与 AI 素材常显，无伪造人气数字 |
| 发布／我的主页 | 图片、名称、说明、来源与分享确认 | 先登录；原型仅生成内存中的发布预览，刷新不保留照片，不公开 |
| 美甲方案卡 | 已选款式、长度、场景、补充需求 | 可保存 PNG／复制文字；支持时主动调用系统分享；返回原照片或创作流程，样图不冒充用户上手效果 |

原型支持浏览器返回、前进和列表滚动恢复；页面底部展开“预览设置”后可切换线框视图，并检查失败、空内容和数据边界。搜索只更新结果区域，中文合成输入保留原控件；异步生成完成也避免打断正在合成的文本。

## 4. 偏好、照片与他人体验

- 显式偏好、长期行为、本次场景、手部特点分开保存；手部特点在消费者端权重较低，不预设未经验证的数值权重。
- 正式版由语言模型结合用户标签、收藏与照片提取特点，生成简短可纠正的描述。自动学习要避免把单次特殊场景改写为长期审美；具体聚合和撤销设计在服务验证后确认。
- “为身边的人试戴”沿用账号审美，只替换本次手图，不覆盖主人手图、特点与长期档案。
- 手部原照片默认本地；用户已允许将照片发送给视觉模型分析。这是按需处理，不等于默认云端长期保存照片。第三方留存条款须按实际服务核对，不承诺供应商必然不存储。
- 特点关键词、偏好和作品是跨设备方向。作品公开发布属于另一项主动公开行为；发布前需说明实际公开内容，不能把本地手图直接随档案上传。
- 游客先本地使用，登录后再设计去重与合并；当前 IndexedDB 收录和账号系统不能直接视为已完成云同步。
- 原型只有独立 `jiaru-consumer-design-v1` localStorage：保存偏好模板、收藏、喜欢、关注与相关选项。照片仅使用内存对象 URL；刷新需重选，不保存照片像素或“已提取特点”。
- 照片试戴与创作分别保存会话描述、等待／结果状态及选款，不因切页串用。发布选图不取消照片试戴任务；换图采用顺序标记，避免旧解码结果覆盖新选择。
- 偏好描述、引导摘要及学习开关的未保存草稿可跨页继续，显式保存后才更新长期偏好；发布标题、说明、来源与权利选择在模拟登录前后保留。会话草稿不代表刷新后恢复或云同步。
- 当前原型没有任何模型、API、上传或真实用户认证请求；模拟登录不持久化，也不创建账号。
- 方案图片在页面内预先编码，缓存按款式、长度、场景、来源流程与描述区分；仅当前方案准备好后启用分享。用户主动点击后先检测文件分享能力，不支持或调用异常时提供PNG保存；取消分享不提示失败，也不宣称已发送成功。分享内容是标注AI示例的方案卡，不附原手图、本机预览链接或账号数据。系统分享在自动检查中使用替身，未向外部接收方发送文件。

## 6. 独立预览、备份与切换

运行 `node scripts/serve-consumer-design.mjs`，访问 `http://127.0.0.1:4318`。不放入 Next.js 正式路由，不导入旧版 CSS，不读取 `.env.local` 或真实账户数据库。服务只绑定本机，按白名单提供原型、图片与本地字体；字体许可随源码保存在字体目录。不支持写请求，浏览器 CSP 禁止网络连接，摄像头权限被禁用。系统分享仅由主动点击触发，不等于原型主动上传数据。

旧版在变更前按当前磁盘保存至 `.backup-consumer-20261020-v1/frontend-current.zip`，包含当时未提交修改。清单 `manifest.json` 绑定716文件的大小与 SHA-256，压缩包 SHA-256 为 `9815c519eb7f11108b14d13ee218cffa7e2e4e635afb59f04f1a67ffb42cac98`。不包含真实密钥、真实用户库、训练目录和训练权重；`public` 下运行时资产按原字节保留。

恢复方法：先验压缩包 SHA，再解压至新的隔离目录，按清单逐文件验真；依赖可复用本机已安装版本，本轮没有重新验证联网 `npm ci`。真实配置与用户数据库需按原运营备份单独恢复，不能从该前端包推断完整业务数据备份。不得覆盖当前工作区。

上一阶段恢复验证：逐文件解压验真通过；恢复目录独立启动 `next dev --webpack` 后 `/`、`/gallery`、`/editor`、`/privacy` 均返回200。生产构建未通过：Webpack暴露原识别调试模块的 `node:crypto`／`node:path` 浏览器导入；Turbopack在沙箱和宿主均遇到CSS子进程提前退出。失败保留在 `restore-validation.json`，不宣称整个旧版生产构建已恢复验证。

本轮精进前另保存已认可设计的当前磁盘快照：`.backup-consumer-refinement-20261020-v1/approved-preview.zip`，7,005,471字节，SHA-256 `f3f2746d32112f4abf5ec7d3eab790ab65d487e85b369de941d6189a64e28b25`。其 `manifest.json` 绑定12个文件，包含当时原型、图片、服务脚本与对应文档；`zipReadbackPassed=true`，压缩包读取验证通过。它用于恢复精进前的设计，不取代完整旧版前端备份，也不构成新的生产构建验收。

切换必须在视觉、交互、服务选型及对应功能验收后另行确认；本轮不切换、不部署、不提交推送。未来正式接入新增偏好／行为／手部特点／作品／关注等契约时，应以独立服务边界实现，再定义鉴权、合并与版本；原型的本地结构不是生产 API 合同。

## 7. 提案评审与验收

- 手机、平板、横屏与桌面检查：320×740、390×844、844×390、768×1024、1024×768、1440×1000 CSS px；同时检查触控、鼠标、键盘和减少动态效果分支。
- 检查首次引导可跳过、无照片可完成、摘要可纠正；换页回退保留会话草稿。
- 他人照片不得覆盖本人照片；本地与云端文案一致；原型不外发图像。
- 收藏与取消收藏、无结果／无收藏、模拟登录后本地发布、关注状态、详情到试戴和方案路径应可操作。
- 生成等待、失败重试与返回输入要可见；样图必须始终注明非本次生成，不能声称已有上手效果。
- PNG方案卡可实际保存且包含示例标识；系统分享须保留下载／复制降级、取消语义与用户主动触发，不自动发布、发消息或伪造社区互动。
- 旧版源文件与必要资产保持变更前字节；完整备份和生产构建失败分别记录。
