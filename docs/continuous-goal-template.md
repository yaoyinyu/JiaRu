# 持续更新 Goal 通用模板

采用“精简Goal启动器 + 可更新目标文件”。Codex Goal只引用文件；目标文件只记录目标、核心要求、当前状态和下一步计划。读取、回写、版本保护等执行规则放在`AGENTS.md`中。

## Codex Goal启动器模板

```text
持续推进<项目目标>，唯一权威目标文件为docs/current-goal.md。

每轮开始按AGENTS.md读取权威文档、目标文件及相关最新证据，按“当前状态”和“下一步计划”继续执行。每轮结束前按可重放证据核对当前状态与下一步；活动目标完成、被证伪或有证据支持路线调整时，切换为下一项唯一可执行里程碑并移除旧步骤。活动尚未闭合时保留它并写明剩余动作；纯治理整理保持模型进度原样。文档与日志按AGENTS.md的变更类型同步。

可以主动调整执行方案和优先级，但不得降低目标要求、改变受保护数据角色或把历史失败改写为通过。只有目标文件规定的全部完成条件通过，才可标记Goal完成。
```

## `docs/current-goal.md`模板

```markdown
# <项目名称>目标

更新日期：<YYYY-MM-DD>  
当前状态：<ACTIVE / HOLD / COMPLETE>

## 目标

<用一段话描述最终交付物和正式成功语义。>

本轮活动目标：<只写当前唯一可执行里程碑；完成、证伪或路线调整后切换，未闭合时保留并明确剩余动作。>

## 核心要求

- <关键质量要求>
- <数据、权限或隔离要求>
- <运行环境与交付要求>
- <唯一完成条件>

## 当前状态

- <已经验证的当前事实与证据>
- <当前最好结果及未通过项>
- <已经关闭的路线>
- <真实外部阻塞；没有则写无>

## 下一步计划

1. <下一项可执行动作、产物和验证方式>
2. <根据第一项结果执行的单一分支>
3. <后续晋级步骤>
```

## 维护入口

本项目的读取、证据追溯、字段保护和同步流程统一见 [AGENTS.md](../AGENTS.md)§3.3。本模板只提供启动器与四段结构；移植到其他项目时，在该项目规则入口明确对应流程与完成条件。
