# 持续更新 Goal 通用模板

采用“精简Goal启动器 + 可更新目标文件”。Codex Goal只引用文件；目标文件只记录目标、核心要求、当前状态和下一步计划。读取、回写、版本保护等执行规则放在`AGENTS.md`中。

## Codex Goal启动器模板

```text
持续推进<项目目标>，唯一权威目标文件为docs/current-goal.md。

每轮开始先读取AGENTS.md、目标文件及其引用的最新证据，按“当前状态”和“下一步计划”继续执行。每轮结束前，根据可重放证据把目标段内的活动目标切换为下一轮唯一可执行里程碑，移除已经完成或证伪的旧步骤，同时更新当前状态和下一步，并同步项目权威文档与开发日志。

可以主动调整执行方案和优先级，但不得降低目标要求、改变受保护数据角色或把历史失败改写为通过。只有目标文件规定的全部完成条件通过，才可标记Goal完成。
```

## `docs/current-goal.md`模板

```markdown
# <项目名称>目标

更新日期：<YYYY-MM-DD>  
当前状态：<ACTIVE / HOLD / COMPLETE>

## 目标

<用一段话描述最终交付物和正式成功语义。>

本轮活动目标：<只写下一轮唯一可执行里程碑；每轮结束必须改写，禁止沿用已完成目标。>

## 核心要求

- <关键质量要求>
- <数据、权限或隔离要求>
- <运行环境与交付要求>
- <唯一完成条件>

## 当前状态

- <已经验证的当前事实与证据>
- <当前最好结果及未通过项>
- <已经关闭的路线>
- <真实外部阻塞；没有则写无>

## 下一步计划

1. <下一项可执行动作、产物和验证方式>
2. <根据第一项结果执行的单一分支>
3. <后续晋级步骤>
```

## 建议写入`AGENTS.md`的规则

```markdown
- 凡任务涉及`docs/current-goal.md`，开始前必须读取其中的目标、核心要求、当前状态和下一步计划；结束前必须以本轮可重放证据更新当前状态和下一步，并同步权威文档与开发日志。已完成的活动目标必须移出下一步，目标段中的活动目标必须改成下一轮唯一里程碑，禁止一直沿用旧目标。
- Agent可主动更新当前状态、技术路线、优先级和下一步；不得静默降低目标与核心要求。目标或正式门确需修改时，必须在权威文档和开发日志中记录旧值、新值、原因和证据。
```
