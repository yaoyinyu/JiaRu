# 纹理边缘精修计划评审与建议

日期：2026-11-05。结论：离线先行、原始模型与产品效果分开记录的方向可行。修订后的全量实验与独立重放已完成：保留4×4覆盖率抗锯齿，关闭本轮两种受限平滑。浏览器产品层实现及验证见下节，原始模型几何单独保留。

## 1. 计划中需要修正的地方

1. **锯齿来源尚未单独归因。** `radial-refine.ts`确实以`radius[bin]-distance>=0`生成二值mask；`fitRadialRadius`产生粗半径，随后Stage B输出新的半径，粗半径缺少平滑不足以单独解释最终锯齿。还应分离模型半径波动、角度分桶、二值栅格化、识别输入缩放、原图回映射、旋转/256纹理封顶及alpha合成。每个环节先用保存输出与解析轮廓做开关对照，保持权重不变。
2. **补齐原始半径与坐标。** `predictions/*.npz`只有boxes/confidence/classes/maskShape/masksPacked。平滑实验应另绑定`raw/*.npz`内真实radius/presence和元数据，并沿原评估计划绑定每候选ROI、center、bins、distance、身份及精度域。禁止把从二值mask重新拟合的半径默认当作Stage B原输出。先重建全部原mask与V0逐像素一致，检查presence与未分配项，再开始比较。历史RAW目录可复用，需核验当前可用性和全部引用哈希。
3. **固定全分母与匹配。** 主表固定100图634真值，636候选完整保留；匹配成功子集只能是辅助表。冻结V0一一对应后做逐甲迁移，另外完整重匹配报告召回、漏甲、额外候选和邻甲重叠，避免通过缩小候选或变化的IoU匹配分母提高成绩。
4. **采用有效的保护门。** V0严格联合0/634，联合通过数零回归保护力很弱。补充逐甲Boundary IoU/F1变化、P5最差分位、对称轮廓距离/HD95、面积误增误减、甲尖/侧缘损伤、拓扑、邻甲交叠，以及基线各单项通过集的迁移。严重回归阈值和允许例数须事先冻结；不在看到结果后选一个“恰好通过”的阈值。meanBoundaryIoU提升0.02可保留为贴边分支目标；抗锯齿分支单独检验覆盖率和形状保真，不强求二值指标同步提高0.02。
5. **修正统计方法。** 连续Boundary IoU差用按源图或已知来源组聚类的配对bootstrap；联合通过率可附Wilson描述区间，并标注同图实例依赖。最小可判别差由冻结的配对差方差、来源簇数和功效约定计算。100张训练域图片用于开发诊断和选型，后续未见质量验收另外安排；来源组不足时相应区间仅作描述。
6. **缩小算法矩阵。** 周期三次插值若仍在原节点取值，会保持原数据；真正平滑应指定正则化或减少控制点，固定周期接缝、过冲限制及甲尖保护。中值/均值窗口宜按轮廓弧长像素尺度选择，再换算角窗；固定k对大小甲面的物理作用差约一个数量级。傅里叶硬截断容易损伤尖角，先作低优先级对照。最大连通块/填孔作为异常拓扑处理，记录实际触发数，避免所有径向mask无差别执行开闭运算。
7. **GrabCut/图割延后。** 旧153候选报告显示GrabCut联合2/141、置信图割131/141且无增益，均已关闭。新输入可建立独立小预算对照，先证明失败与RGB边缘有关，再消费全清单。`refine-mask-with-edgecut.py`要求完整float32 logits；半径减距离是几何径向量，需显式说明先验语义及尺度，二值mask和校准置信度应分别处理。
8. **覆盖部署口径。** 全原图100源终评是开发基线；浏览器路径还会缩放识别输入，再映射原图、提取与旋转纹理。必须绑定实际部署尺寸，分别标记识别域px/原图px/纹理px。保存mask直接缩放，无法替代模型在缩放输入上运行的真实输出。零推理阶段只使用已经保存的对应尺寸捕获，缺少时明确登记后续有界部署验证预算。
9. **细化移植与发布。** 原始Stage B半径/presence与原始解码保持单独对拍；新增产品层单独记录版本与摘要。整数形态学及最终mask/uint8 alpha可逐位对拍；FFT、样条等浮点步骤先冻结算法、运算顺序、舍入和数值容差，另检最终阈值像素零差。产品层改变输出后应生成新的产品处理版本/组合发布绑定并走登记验证，保留原模型身份作血缘。“生产manifest默认启用”与“发布身份零变更”需要在计划里消除冲突。
10. **性能实测。** 固定窗口均值可为O(N)，直接中值通常为O(Nk)，FFT为O(NlogN)，多次形态学/覆盖率采样还与ROI面积和实例数相关。冻结最大ROI、10实例、移动低端机P95和峰值内存后实测，Worker15秒超时只作故障保护。

## 2. 推荐实验顺序

| 顺序 | 分支 | 目的与继续条件 |
| --- | --- | --- |
| A | V0原始半径、坐标与二值mask重建 | 完整全分母、原字节一致，原失败与未分配实例保留 |
| B | 原始轮廓 + 边界带4×4覆盖率alpha（另加2×2对照） | 优先处理显示台阶；冻结原硬mask作为质量参考，分别记录产品alpha支持域和面积，不沿用限制alpha只能向内的逻辑来裁掉覆盖率；检查白/黑/棋盘底色光晕与预乘alpha颜色 |
| C | 一种轻量、按弧长尺度且限制位移的周期平滑 | 减少真实半径毛刺；对比B与C+B，保护甲尖/侧缘，统计改善与受损分布，不先串全部算法 |
| D | 窄带RGB引导边界搜索 + 周期位移正则 | 若B只改善外观、C仍偏离甲缘，再研究沿原轮廓法线的小位移搜索；高光/花纹和低对比处允许保持原轮廓，种子、位移范围、步长、能量与预算另冻结 |
| E | 必要时形态学、样条、GrabCut/图割单项对照 | 仅在对应失败类型有证据时开启；图割边界band与性能单列，胜者才进入组合 |

B中的覆盖率可通过连续极坐标轮廓重建后对边界像素超采样，或从显式轮廓计算覆盖率。直接放大已有二值mask的分辨率不会恢复丢失的亚像素轮廓。径向差并非欧氏有符号距离，若用距离alpha应先构建相应距离域，避免陡侧缘羽化宽度失真。甲面外半像素的覆盖率可能混入肤色，须冻结颜色取样与alpha合成策略一起验收。

按有限B/C变体完成100源全量配对诊断，开发选择与最终未见验收分开；候选配置和严重回归门在执行前冻结。原始模型完成门保持其原数据与阈值。

严格联合均为0/634，完整重匹配均无新增漏甲。4×4的平均soft IoU相对原硬mask变化−0.000369（预注册下限−0.001），636候选共784016个部分覆盖像素。该分支改善亚像素显示，真实甲缘偏移继续由原质量指标记录。634甲属于既有训练开发域；已知来源组只有1个，源簇bootstrap退化为点，来源独立置信区间记为不可估；另列100源图等权配对的描述区间和近似最小可判别差，详见selection报告。

产品实现：原Stage B输出之后计算`radial-coverage-v1`，保留原分段常数角桶半径，边界带4×4超采样；`NailMask.coverageAlpha`携带独立uint8覆盖率，原`data`、原输出调试回调与对拍层保留。纹理提取为覆盖率连续缩放、RGB直接从原图采样，再合成alpha；避免把原图先缩成低分辨率mask，也替换原产品分支的最近邻alpha取样。原软边`alpha`路径保持既有契约。

验证：合成ellipse、周期接缝及图像边界fixture共6项测试通过；600×800实际WASM4实例原硬mask与既存三方参考零差，Python↔TS覆盖率零字节差。浏览器Canvas保留原图细条纹动态范围255、原透明背景，alpha≥64的恒色样本颜色误差≤2/255；10枚800×800最大ROI的桌面20次处理P95约107ms。真机性能和真实低对比边缘视觉验收继续单列。完整浏览器接入及工程验证见当日开发日志。

覆盖率采样另行预注册复核：全部636候选、1461615个边界带像素，以同一保存轮廓的8×8采样为数值参考，硬二值/2×2/4×4的平均绝对覆盖率误差分别0.157789/0.057641/0.020992；4×4相对硬二值约降低86.70%。此项衡量栅格化误差；真实甲缘定位继续采用上述真值贴边指标。证据`coverage-accuracy-plan.json`与`coverage-accuracy.json`。
