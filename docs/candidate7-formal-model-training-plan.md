## 1. 问题结论

candidate6 已证明继续补强正样本能提高实例召回，但未解决整图直接提取：相较 candidate5，匹配甲面从464升至491、漏甲从90降至63，然而重复从8升至18、额外候选从23升至30、无效预测mask从23升至29，直接可提取图片从39降至38。传统mAP门通过不能覆盖该失败。

现有浏览器后处理仅能按候选框重叠抑制部分重复，不能补回漏甲，也不能把无效或不完整像素mask修复成完整甲面。因此不得把后处理微调作为candidate6发布依据。

## 3. 数据方案

1. 保留candidate6已授权并物化的120张/636个完整甲面训练真值与160张训练困难负样本。
2. 从既有商业训练授权但尚未进入train/val/test/holdout的真实素材中建立全新来源候选；先按父来源组排除冻结test100、val30和已消费留出，再做源图完整性门。
3. 新增正样本目标不少于80张，优先覆盖：
   - 双手8—10甲、高密度相邻或交叉姿态；
   - 中远景小甲、强透视和横向/侧向拇指或小指；
   - 透明、裸色、低对比、镜面高光和复杂装饰但甲板边界可确认；
   - 复杂真实背景、局部遮挡但所有纳入真值甲面仍完整可见。
4. 每张源图先通过清晰、完整、不裁边、单一真实场景门，再逐甲形成完整polygon；机器合法性、同图零交叠和提示几何只作前置，必须通过原分辨率整图及逐甲放大终审。
5. 新增训练负样本只使用全新来源，针对候选重复/局部区域误定位的视觉混淆物；不得复制冻结test100图片、标签、裁片或父来源组。

## 4. 模型与后处理实验

- 基线A：candidate6权重继续训练，仅用于衡量新增数据收益。
- 主实验B：更高容量的YOLO分割基座；基座文件、版本和SHA-256必须在训练授权前固定，禁止运行时联网漂移。
- val30上同时审计原始输出与部署后处理输出。后处理只允许确定性规则：置信度、候选上限、mask合法性和重叠抑制；所有参数必须由val30选择并写入候选manifest草案。
- 如果后处理降低重复却造成val30召回或完整mask比例退化，则拒绝该规则，不进入test。
