# 数据身份、来源与资格隔离

本文件是根目录 [AGENTS.md](../../AGENTS.md) 的专项规则，命中其读取条件时必须在执行前完整读取；多主题任务须同时遵守所有相关文件。当前状态、样本数、预算与路径绑定以权威文档及可重放报告为准。

同时读取：涉及报告时读[冻结证据与重放](evidence-replay.md)；涉及图片发送时读[整图视觉审核](visual-review.md)。

## 真值索引、角色与血缘

- 训练真值规模必须按稳定图片身份去重，禁止按`training-truth-*.json`报告文件数直接累计；同一`item.fileName`存在多个批准报告时，只有图片身份、annotation SHA-256、来源组和mask数完全一致才可选最高序号报告作为规范记录并计数一次，任一字段冲突必须拒绝训练物化。

- 创建新的训练真值返修manifest前，必须读取权威`training-truth-index-v1.json`并按`canonicalTruths[].fileName`精确查重；该索引不存在`items`清单，禁止用错误字段或仅凭源筛选inventory推断图片尚未登记。查重失败或重放发现冲突时，新增报告不得晋升并须恢复原权威索引。

- 受保护派生图的父图片SHA-256和父来源组同样受保护；角色审计必须同时检查当前身份与父血缘。冻结快照的图片路径须从权威清单及实际目录结构解析，并在像素扫描前逐文件核验存在性及SHA-256，禁止忽略core/stress等目录层级后以不完整扫描宣称通过。

- 全split盘点必须分别保留上游数据集角色与当前冻结split，显式绑定逐图角色迁移；当前内部val曾在上游训练使用不能作为正式来源独立验证证明，也不能回流当前train。新版返修进度页省略的旧源质量排除须沿绑定输入链保留，`currentDecision`优先于旧`decision`，不得把缺席记录改记为未审核或已通过。

- 跨split记录的ordinal仅为角色内局部编号，不得单独作为全局身份键。合并或逐记录对照必须使用split、fileName和图片SHA-256组成稳定身份，并核验原记录基数、角色和顺序，禁止因编号碰撞静默覆盖记录。

- 组审核构建器不得把非活动成员统一推断为源质量排除；必须按稳定身份读取权威`currentSourceDisposition`，分别继承`source_quality_excluded`、`source_marker_isolated`等处置。错误假设及其失败须保留，另立版本修复，不得借修复恢复被隔离成员资格。

- 角色索引的`records[].currentTruth`可能只承载train真值；存在独立`currentInternalValTruthRecords`时，内部val必须按split、fileName和图片SHA-256匹配该权威列表并核验标注绑定。禁止把val角色行的空train真值槽解释为缺失标注、缩减val分母或放松校验。

- 准入证据账重建一致不等于训练许可；旧报告缺后来新增的资格布尔字段时，须核对其完整来源组、逐源实审判决和绑定哈希，在新版本兼容复算，保留旧误计。模型标记验收须明确组件、模型身份和验收规则，不能仅凭“next-model”等模糊文字推定训练依赖循环或放宽门。

- 图片文件名中的training、train或val字样不构成当前数据角色；资格汇总和隔离须逐记录按权威稳定身份中的split分区复算，并同时保留原成员、真值和角色。角色分区断言失败时不得继续晋升，已落盘的错误汇总须保留并另版修正。

## 采集资产与来源凭证

- C2PA内容凭证只作为来源与血缘的补充证据：CLI退出0、局部签名/文件哈希通过或供应商名称均不能覆盖整体凭证失败，也不能证明训练资格。`allActionsIncluded=false`或未列ingredients不能推断没有参考输入；声明的水印动作须登记，不能凭原图未见文字视为水印/模型捷径通过。验证器、公开信任列表和原文件字节须绑定，失败不得用放宽证书用途或改签原图绕过。

- 来源组的采集资产清单可能大于当前split成员清单。来源隔离检查须显式盘点同帖未入split的相关资产，新增召回只查询此前未查询的精确图片身份，保留旧目标/图对分母；同帖相关资产不能自动记为父图、真值或训练候选。未在角色索引出现的资产不得推断为质量排除，须继承其权威原处置或另作原像素源质量裁决。

- `acquisition_album_related_asset`等采集类别不证明图片未进入历史split；源质量报告写入前须按精确SHA盘点现行角色与资格库存。已有train/val角色及原质量排除应继承并明确记录，不能因来源组拥有者是另一张图就断言本资产无角色或改写其角色。

## 来源召回、图对裁决与资格投影

- 来源组因标记干预不可解释而隔离时，只变更训练资格，须保留完整split、原数据角色、已审完整mask真值与历史失败；不得把隔离写成标记消除、来源独立或模型质量通过。日后重新纳入须建立新版本整组审核证据，禁止按模型输出只取已通过子集回训。

- 已被当前候选模型用于误检筛选、错误分析或样本挑选的困难负样本，如果其误检结果随后影响训练集或返修决策，就不得再充当下一候选的未见独立发布留出；应在训练方案与样本角色冻结后另生成并冻结新来源留出，禁止按模型输出挑选“零误检图片”伪造泛化通过。

- 感知近重复召回只能生成待目视候选，不能把局部特征匹配或无命中当作来源独立证明；须保留预注册算法、覆盖范围、正控与逐对裁决。重放验证不能代替原图目视审核，也不得使用受保护模型质量结果挑选训练素材。

- 已确认来源复用不等于已确认拼贴格位、裁切、镜像或像素对应；用其作数值方法正控时须另绑定定位/几何假设。正控失败只关闭当前方法的解释资格，保留既有来源隔离与未决分母，禁止按最佳分数倒写目视定位、调高原阈值追认为通过或继续计算/解释候选结果。

- 来源图对原像素确认与已消费测试同源时，须隔离完整当前来源组的后续训练资格，并绑定受保护参考角色、两端图片及实际查看证据；原train/test角色、完整mask真值和全部冻结审核分母保持。资格台账须从未隔离成员重新计算候选及缺口，不得沿用旧候选数、将同源失败写成不同源或通过更名来源组绕过保护。

- 已整组禁止后续训练的来源组，其剩余待裁图对继续保留在原分母；后续图对裁为不同也不能自动恢复资格。资源受限时可优先审核按稳定身份关联现行准入候选的待裁图对，须先校验完整旧队列与全部待裁记录，再冻结候选关联、隔离关联的分区及原序选择，禁止按模型质量结果选样、删去隔离组待裁或把优先级变化写成来源独立通过。

- 已有ROI或几何证据的来源组后来被资格隔离时，须先按原完整来源范围校验全部旧记录的身份、来源、真值及分母，再投影到当前候选计算覆盖率；被隔离记录仍须验真并在历史证据中保留，不得先过滤以隐藏坏记录、改写原证明或恢复训练资格。

## 图对队列、继承与特征缓存

- 增量查询目标与旧目标不交叠，并不保证无向图对不交叠；旧参考可能变为新目标。合并来源图对须按两端精确图片SHA去重，角色/来源组及已实看绑定一致时另记旧判决继承，不把反向观察计为新增实审或新增污染。准备包的新图/旧图及待看页数须从绑定清单复算，不用估计数晋升。

- 多图对审核批次须在像素读取前逐条冻结并核验两端图片SHA、来源组与角色；队列序号相邻不证明共用目标，新目标缺少完整实看证据时不得继承旧目标内容或结论。

- 候选资格投影后的审核序号须从实际筛选记录按原序读取，禁止用起始序号加一推导连续编号；预检不一致须保留失败并校验筛选谓词和完整队列，不能按错误编号修改权威清单。

- 图对继承批的完整旧队列/待裁角色与稳定身份校验必须先于任何像素解码和不可覆盖输出；未选中行也须验真。测试夹具的原始与预期记录须隔离深拷贝，禁止对象别名令篡改同时影响两端；用于断言“不得到达”的侦察异常不得被预期的assertRaises类型吞接，须验证解码及输出确实未发生。

- `freeze-inherited-native-pair-batch-v2.py` 的 `maximumPairs` 是原序前缀的精确抽取条数；不足常规批次上限的尾批须按实际条数设置并逐项匹配 `selectedOriginalQueueOrdinals`，不能只写上限后依赖裁决清单截断。参数错误须在新计划版本修复并保留旧失败，不放宽图片、角色或发布质量门。

- 近重复召回的正控源或父参考可能位于比较参考和目标域之外，特征读取清单须显式包含它们；特征读取分母与实际比较分母分别冻结，不得为满足正控把域外控制晋升为训练目标或改变受保护参考集合。

- 继承或重建图像特征缓存时，须保留原图解码器、颜色/灰度域、缩放及特征算法配置；相同图片SHA或正控布尔通过不能证明特征域等价。原控制结果不能精确重建时须保留失配及已消费读取，另版修复读取域，不得覆盖旧特征或追认原失败为通过。依赖导入成功也不能代替完整训练的资源可执行证据。
