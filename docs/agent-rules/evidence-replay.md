# 冻结证据与只读重放

本文件是根目录 [AGENTS.md](../../AGENTS.md) 的专项规则，命中其读取条件时必须在执行前完整读取；多主题任务须同时遵守所有相关文件。当前状态、样本数、预算与路径绑定以权威文档及可重放报告为准。

同时按证据主题读取数据、视觉、训练或数值专项；本机命令另读[开发与排障](development.md)。

## 身份、序列化与保真

- 运行日志可能滚动清理；采集须冻结时间/ID边界、原记录分母与脱敏字段/正文SHA。原数据库完整重放因缺行失败时必须保留失败，只能单列仍能按原精确ID验真的事实及快照汇总；禁止把原分母缩成剩余日志后声称原窗口完整重建或网络根因已闭合。

- 只读分析脚本必须以“接受候选集重建与既有冻结/权威报告逐图逐实例同构”作为硬保真门，门限口径须与预注册计划逐项比对；保真门未过时输出`reconstruction_mismatch`并拒绝给出任何结论，禁止在重建口径未对齐时继续出结论。

- 哈希绑定报告的未来引用须使用与实际落盘完全一致的编码及换行字节，优先复用同一序列化字节并以二进制写入；禁止按LF计算SHA后让Windows文本写入器转成CRLF。产物冻结后发现内部绑定不一致须保留旧版与失败诊断，通过新版本修复，不得覆盖旧报告或放宽字节一致性门。

- 冻结计划引用现行状态入口时，须先保存入口的原始字节不可变快照并绑定快照路径及SHA-256，禁止把可更新入口本身当作永久输入。历史计划已绑定可变入口时，须保留原计划；仅允许用SHA-256完全相同的原字节快照显式解析历史状态，并另立重放读取器版本，不能把新版现行内容冒充旧输入。

## 汇总、字段与跨平台读回

- 重建现行处置报告时，所有 `current*` 汇总须按稳定图片身份合并最新版逐甲裁决后复算，不能原样继承旧版活动范围的子汇总；旧值与失败必须保存在历史绑定中。已冻结报告发现过时汇总时须保留旧版，通过新版本修正，不得覆盖原报告。

- 通用报告工具的输入槽须逐项遵循其schema：工具会解析全部`inputs`为JSON时，脚本/图片等非JSON血缘应另置专用绑定字段；写计划前逐槽验证存在性、哈希及解析类型。角色查重须读取权威`records[].identity.imageSha256`，不得用不存在的顶层字段得出零命中；已冻结的错误计划或检查须保留，通过新版本复算。

- 不同split的覆盖率、可达性比值及分母必须分别命名并逐角色重算；构建字典或JSON前须检查重复字面量键，禁止以共享`ratio`等字段让后写split静默覆盖先写结果。发现冻结汇总字段覆盖时保留旧计划和失败，另版修复字段，不改变成员、角色或质量门。

- 哈希绑定报告若以仓库相对路径作为字典键，写入与读取须统一为斜杠规范键（如Path.as_posix），不得混用Windows原生分隔符和手写斜杠。发现已冻结键不兼容时须保留原报告与失败，以只修读取的另版适配器承接精确未消费预算，禁止覆盖原键或重启已消费模型输入。

- 内存真值记录与冻结JSON读回记录的完整保真比较，应使用权威序列化器的字节并保留身份、点序和存储域；tuple/list容器差异不能当作真值变化，也不得为迁就容器类型重写原标注。比较失败须保留原源码与失败，核验已写产物后仅续接未完成部分。

## 脚本修复、终态与存储维护

- 翻版审计脚本的变量改名须使用词法或AST定位，禁止对全文作变量名字符串替换而改损SHA、路径、角色等常量。期望绑定损坏与权威产物漂移须分别取证；坏版和失败保留，另版恢复原已冻结合同，不得修改权威产物或以其当前哈希重定义约束。

- 重放一次性核验脚本前必须确认其只读入口；没有只读入口时，应另立重放器，按明确结构边界执行冻结断言与结果构造并比较旧报告，禁止再次调用不可覆盖写入器、删除旧输出或改用覆盖模式绕过已有产物。初次误调用及其失败须保留。

- 审计脚本版本迁移中的整数须按字段或精确表达式定位；队列序号映射不得应用到来源数、角色数、图对分区或冻结分母，生成后须逐项与权威合同对照。

- 等待或停止句柄返回终态时，须先核对实际退出码、报告是否已生成及绑定，再决定后续动作；拟中断不证明实际发生中断。已生成的不可覆盖报告只允许使用只读重放入口，禁止在等待返回值尚未检查时紧接再次调用写报告入口。重复写入拒绝须保留，不改写原报告或重跑模型。

## 捕获保留与存储维护

- 数学诊断可在新合同中预注册只保存必要边界与最终RAW，全部中间阶段仍须独占持久化开始/完成事件及完整数组形状、存储域、字节数和SHA-256；重放必须重新计算全数组并核验全部哈希、输入链和最终门，不能只复核摘要。阶段失败不允许静默重启，旧合同要求保存的RAW不得追溯删除或用新策略冒充完整重放。

- 冻结证据的透明压缩或硬链接去重须先绑定原路径、完整长度/SHA及终态，拒绝越界与并发写；只合并逐字节完全相同的不可变文件，保留原路径并对共享内容设只读保护。原子替换须具备备份及故障恢复，操作事件持久化后执行；维护后全量重验全部原路径/SHA与权威报告。共享别名不能单独解除只读后改写，新增产物必须另立版本；按文件ID去重后的分配空间、路径逻辑体积及磁盘剩余空间须分别报告。

- 验证器的首次写入/只读重放布尔开关不得被同名读回报告覆盖；两种入口须分别验真。发现模式分支错误时保留原源码和失败，另版只修读取/保存分支，不得重训、重跑模型或覆盖原结果。
