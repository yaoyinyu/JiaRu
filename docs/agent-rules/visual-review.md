# 整图视觉审核与标注返修

本文件是根目录 [AGENTS.md](../../AGENTS.md) 的专项规则，命中其读取条件时必须在执行前完整读取；多主题任务须同时遵守所有相关文件。当前状态、样本数、预算与路径绑定以权威文档及可重放报告为准。

同时读取：[数据身份与来源](dataset-provenance.md)、[冻结证据与重放](evidence-replay.md)。

**现行输入规则：只发送完整原图，不新增或发送裁片、分块、拼图或重排面板。下文涉及旧裁片、并排页或辅助列的规则仅约束历史证据解释与坐标保真，不构成新增此类输入的许可。**

## 图片输入、资源边界与继承

- 视觉审核向模型发送图片时，必须遵守用户“整张整张审核，不要裁开”的要求：每张完整图片作为独立图片输入，可一次输入一批正常素材，减少反复携带聊天上下文的请求；不新增或发送裁片、分块、拼图或重排面板。不得为显示或体积门缩小原图、有损压缩或丢弃区域；必要的无损编码优化须核验原尺寸、RGB存储域与像素完全一致。按图片SHA去重，已有满足当前审核目的的完整实审事实应继承，不重复发送；旧摘要不足而必要重看时须记录原因和体积。整图被工具缩放或不能满足资源门时，保留未决和具体缺口，改进完整图发送/显示方式，不自动改回分块。历史分块实际查看按原绑定保留，不重发、不计新实审；正常图片体积不能无证据归为巨量网络使用原因。

- 向模型发送审核图片前，按精确页面SHA-256与实际文件字节建立本批清单，分别统计新增页、继承页和必要重看页，并说明用途与文件体积；完整绑定可继承的旧页不重复发送，必要重看须记录原因和体积。文件字节、base64估算与实际网络流量分别记录，不得据文件大小宣称没有客户端重传或冒充实测流量；持续上传授权不另设逐批审批，控制发送量也不放宽原像素质量门。

- 图片体积不足以代表完整模型请求：须区分唯一审核页文件、模型请求压缩日志中的准备字节、代理进程收发合计和实际连接上传/下载。发现百MB级请求时停止增加项目图片输入，先冻结近时请求与线程归属证据、定位上下文规模；pubsub重连不自动证明推理请求体重传，代理/TUN进程总量不自动归属Codex。此资源处置不改变图片质量门、上传授权、数据角色或Goal最终完成语义，也不自动暂停Goal。

- 审核工具明确提示图片被缩放显示时，该显示不得作为原像素视觉审核依据；须保留未决并解决完整图片的原尺寸显示方式，不能违背用户整图要求改发裁片、分列或紧凑重排面板。仅设置`original`参数不能覆盖工具实际缩放提示。

- 完整原像素查看证据可按精确图片SHA、RGB存储域、原尺寸及全部审核页绑定继承；继承只复用图片证据，新图对必须另作显式裁决，当前角色和父血缘须从现行队列读取。缺页、缩放、未实际查看或身份/像素域漂移必须拒绝继承；新增实际查看量、复用量和去重累计量必须分别统计，禁止把旧查看或新建但未查看的页重复计为新增实审。

- 请求体超限时不得新增图片输入；完整冻结图片证据仍可只读重放并用于另作新图对判决，须复验全部原像素覆盖、实际查看和当前身份/角色。旧内容摘要含其他目标比较或“不同源”等旧结论时，只继承图片内容事实，显式排除旧图对判决；内容不足须保留未决与具体缺口。此路径须分别记录新增实看0、图片输入0和继承量，不能宣称零网络流量、守卫恢复或来源独立通过。

- 用户在当前任务明确恢复图片发送并要求控制体积时，须依据其最新指示另冻结有界发送规则，逐页绑定与记录文件字节，并将完整请求体/历史上下文单独采样；旧资源守卫失败必须保留，不得改写为恢复或模型质量通过。该资源规则变化不得改变原像素审核、角色隔离或发布质量门，持续上传授权不增加逐批用户审批等待。

- 审核页可直接绑定满足发送体积限制的原图编码字节，须先核验原文件SHA、RAW存储域/原尺寸/完整覆盖与实际工具无缩放；不必为统一格式重编码成更大的PNG。文件字节与工具返回的编码载荷须分记并核验各自上限；原图固有低清不得因文件小而放宽源质量门。

- 完整单图需要定位边条辅助显示时，只可在源图区域之外添加，并绑定原尺寸、原点、全部源RGB与覆盖；不得缩放、裁切、重复或重排源图。定位页与底条不得进入训练/推理数据；显示正控通过只闭合其明确范围，不能批准标记语义、模型因果或追认旧未决为通过。

- 发送真值与预测叠加的审核图时，说明与图例须明确区分「经人工审核的参考标注」和「当前模型预测」，不能只用不解释的GT缩写让参考轮廓看起来像模型结果。人工/SAM辅助真值画得准确不构成自动识别、模型质量或发布通过；每个模型候选仍须保留自身身份及实际裁决。

- 整图预算冻结前必须核验图片是否为历史派生裁片，不能把“完整编码文件”当作“完整父原图”。派生身份仍保留原角色和分母，只能继承合格旧实审或从权威父血缘绑定解析完整原图；缺父SHA/来源组时保留未决，禁止凭文件名或短哈希补认、发送裁片或用其裁为不同。误发须冻结实际输入、无效范围和已消费预算，另版仅续接未消费输入，不追认原失败为整图通过。

## 源质量、完整甲面与返修

- 甲面标注的提示几何审计通过，只证明mask与提示几何一致；不能替代原分辨率视觉审核，仍须检查漏甲、甲面不完整、重复及皮肤、衣物、背景污染。

## 完整甲面与源图准入

- 优先审核完整可见甲面：每枚完整露出的指甲必须恰有一个覆盖全部可见甲面的完整mask。只覆盖颜色、装饰、甲尖或其他局部即为返修失败，几何通过也不能例外。

- 返修透明、低对比或延长甲时，优先用多个正点分别覆盖有色甲面与透明甲尖，并把定向负点放在邻近皮肤、衣物或背景污染区；禁止把正点放入污染区。多点提示仍只是候选生成手段，必须通过原分辨率视觉审核。

- 任一应标甲面被图像边缘裁断或不可完整见到时，须整源排除，不能反复返修补造；`box-center`、`center-negative-corners`等提示模式仅用于生成候选，仍须通过相同原分辨率审核门。

- 模糊、失焦、低清到无法确认完整甲面轮廓，或存在应标甲面裁断、残缺、仅局部露出的源图，必须在源图筛选阶段排除；此类图片及其派生物不得进入模型训练。源图筛选通过也只代表待标注候选，完整mask逐甲原分辨率审核通过前`trainingUse`必须保持`prohibited`。

- 质量分片审核必须以审核页报告中绑定的输入分片路径和SHA-256为唯一清单来源；工作区内即使存在同编号的`review-*.csv`或其他旧分片，也不得按文件名猜测或混用，写决策前必须复验报告绑定路径、哈希和条目数。

- `build-reviewed-sam-repair-prompts.py` 的 `keepPromptIndices` 使用从 1 开始的提示序号；编写返修清单时不得按数组的 0 起始索引填写。

- 粗模型候选数略高于已由原图冻结的完整可见甲数时，确定性置信度裁剪只能用于候选生成，且裁剪上限必须预先固定；所有被裁候选仍须在原分辨率原图确认是非甲面。若裁掉真实甲面、候选不足或超过固定上限，必须转返修/混合路径，不得用排序改变真值分母或自动批准mask。

- 父截图可用但派生区域选错时，应按父文件 SHA-256 和稳定 `sourceGroup` 替换旧区域，并保持一父图一派生区域；禁止把新旧区域重复计数，也不得因此误排除父图。

## 标注验证、真值修复与持久化

- 冻结发布测试候选前必须逐文件验证多边形合法性与同图零交叠，并复算图片、标注、图片/标注联合及聚合清单哈希；冻结门发现假阳性或拓扑错误时必须回到原图修正并重建上游审核统计，禁止用容差或忽略错误绕过。

- 当透明、低对比或相邻长甲在多轮 SAM 紧框/多点提示后仍持续合并皮肤或邻指时，可以切换为原分辨率人工多边形；人工多边形必须逐甲覆盖完整可见甲面，并继续通过多边形合法性、两两零交叠、提示/外接框几何审计和原图局部放大视觉复核，禁止把“人工绘制”本身视为通过依据。

- `build-reviewed-manual-polygon-repair.py` 清单中的 `nails[].sourceIndex` 使用从 1 开始的原标注序号；混合返修只允许保留已完成原分辨率视觉审核的polygon，脚本产物始终是候选，不能因合法性、零交叠或几何通过而自动晋升训练或test真值。

- 已批准真值在原分辨率复核中发现裁边、局部甲面或污染时，先冻结旧快照、分母与失败判定，将指标保留为历史诊断；按绑定的完整split清单重审并建立新的修复证据版本，禁止只删模型漏检图、就地缩减分母或把旧失败重算为通过。漏检变化应按同一图片及真值序号区分新漏、恢复和持续漏检，不得仅以每图漏检数净差代替实例迁移。

- 源质量审核必须检查完整源图中未被旧标注覆盖的甲面，不能以旧label数量作为真实完整甲面数。发现额外局部甲面须整源排除；旧ROI误标为皮肤时，保留原快照与失败分母，在新版返修清单显式绑定误标序号及新完整甲面数，禁止就地删旧ROI后重算历史结果。

- 原像素审核须逐批持久化稳定图片身份、页面SHA-256和逐甲裁决；会话临时累计不得作为唯一证据。累计失效时只能依实际工具调用记录恢复已查看绑定，禁止用预期清单补充未查看文件。

- 原像素多边形JSON可能使用`{x,y}`字典点或`[x,y]`坐标对；读取须保留权威存储域、点序、分母与图片身份，并对已有支持形式验证像素同构。遇到未支持表示须保留失败，另立读取器与产物版本，不得改写真值标注来迁就旧读取器。

- 字形支持域（自动检测或手工包络）只是控制候选，须原像素复核完整文字消除、背景语义及对应空白/移位控制；支持域较稀疏、几何合法或保护带零变化不能自动批准。放大的坐标辅助列只用于定位，质量裁决仍基于未重采样RAW并绑定各列原点。

- 提示分割模型的公共结果可能按置信度过滤，返回数量不等于提示数；按提示身份建立完整分母时，须在过滤前持久化全部mask/logits、分数与提示索引，并另存实际保留集合。缺项不得压缩分母、按结果位置猜回提示身份或默调阈值；观察接口修复须保留旧失败，先通过新独立控制，再续接精确未消费真实输入。

## 历史派生审核页的解释与坐标核验

以下三条仅用于解释和核验已冻结的历史裁片、网格及并排页。当前新增审核输入统一遵守文件开头的完整原图要求；历史页显示不足时回到完整父原图核验。

- 返修审核裁片须依据完整原图和新版多边形重新取景；旧候选框或旧裁片可能漏掉透明甲尖，不能用其边界代替真实甲面边界。裁片截断须修正取景，只有完整源图本身缺失必需甲面时才适用源质量排除。

- 使用坐标网格等绘图辅助时，须保留未加网格的原像素并列参照，绑定源图、裁片原图坐标、页眉偏移和像素保真；取点须统一到原图坐标域。网格、重放和几何检查不能代替真实甲缘的原像素视觉裁决。

- 并排原图/mask页须按两列各自原点及页眉偏移对齐后判读，不能把显示列偏移当作甲面或轮廓缺失；初步疑点须在写入最终视觉报告前用原图坐标复核。
