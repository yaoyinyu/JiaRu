## 1. 目标与非目标

**目标**
- 让 Stage B 的半径头**自己输出连续半径**，从根上消除边界锯齿，而不是在后处理里遮。
- 把严格联合从当前 **248/634** 推向 **539/634** 门。

**非目标**
- 不改解码口径、不改门、不改真值、不改评测集。
- 不改后处理（`radiusSmoothing` 保持关闭；它的证据已证明只能治表）。
- 不导出 ONNX、不切换生产 manifest（属发布动作，另行立项）。

## 2. 为什么这是当前唯一有证据支持的路线

| 事实 | 数值 | 来源 |
|---|---|---|
| 真值半径的角度域抖动（相邻 bin 差的 std） | **0.165 px** | cycle096（634 甲） |
| 模型原生半径的抖动 | **3.14 px**（二阶差分 std 5.29） | cycle096 / 094 |
| 差距倍数 | **19×** | cycle096 |
| 后处理平滑在原生半径上的真实增益 | 248→248（τ=0.7）／248→281（τ=2.0） | cycle094 / 095 |
| 重拟合代理指标（曾误读为 420） | 只在「从 mask 重描轮廓」上成立 | 092 / 093 |

**解读**：真值本身极度平滑（二阶差分中位数 1.4e-14，说明真值半径是圆弧/直线派生），而模型输出抖动 19 倍；后处理在真实输出上要么不触发（τ=0.7）要么伤指标（τ≥2.0）。**抖动是模型的产出缺陷，不是解码缺陷。**

**为什么现有损失管不住抖动**：`native-radial-training-loss.py:13` 是
`F.smooth_l1_loss(radius / 8, target_radius / 8, beta=.125)` —— **逐 bin 独立回归**，bin 之间零耦合。当误差超过 1px 后 L1 梯度恒为常数，网络没有任何动力让相邻 bin 连续；而主导损失（mask BCE + Dice）只看解码面积，小幅抖动几乎不改变面积，因此不被惩罚。抖动因此稳定存在。

## 3. 正则项设计

**形式**（加在 `radius / 8` 空间，与现有 `radial` 项同尺度，便于 λ 横向比较）：

```
L_smooth = λ · mean_i ( r[i-1] − 2·r[i] + r[i+1] )²      （i 按 2048 bin 循环）
```

**为什么用二阶差分而不是一阶（TV）**
- 光滑圆的半径二阶差分幅度 ≈ ρ·Δθ² ≈ 6.6e-4 px（ρ=70、2048 bin），一阶差分 ≈ ρ·Δθ ≈ 0.21 px。
- 二阶差分对**整体形状**（椭圆度、倾斜、大小）几乎零惩罚，只惩罚逐 bin 高频抖动 → **保角**；一阶差分会把形状往圆里拉，损伤方形/杏仁甲的侧缘。
- 真值侧该量本就接近 0（0.188 std），因此正则项与监督信号**同向而非对抗**——这是它可行的前提，已实测。

**循环边界**：bin 0 与 bin 2047 必须互为邻（与解码/bins 口径一致），否则会在接缝处制造假边界。

## 9. 验证门与停止条件（预注册、可证伪）

评估**必须**在原生半径上用 cycle094 harness，禁止使用"重拟合轮廓"的代理指标（cycle092/093 的教训）。

- **成功**：严格联合 **≥ 539/634** 且 meanBoundaryIoU ≥ 0.75 且 meanBoundaryF1 ≥ 0.90 且 原生半径抖动 **≤ 0.5px**（真值 0.165 的 3 倍内）。
- **部分有效**：联合相对 248 有显著提升（配对二项 p<0.01）但未达 539 → 记录为中间态，附 Wilson 区间与最小可判别差，不宣称达标。
- **反证（明确失败，立即停线）**：抖动降到 ≤0.5px **但**严格联合无显著变化 → 结论为"抖动不是瓶颈"，此路线终止，预算转向形状/位置误差。
- 任一阶段指标反向（联合下降 or 抖动上升）→ 停止，保留现场，写 dev-log。

## 12. 结论（2026-11-17 执行完毕）：§9 反证条件成立，路线终止

三臂全部完成训练、两遍完整重放与六步终评，用 cycle097 在原生半径上复算（保真门零像素差）：

| 臂 | 严格联合 | +/− | 配对 p vs 90 | 抖动 |
|---|---|---|---|---|
| 90 基线 | 248 | — | — | 3.1631 |
| λ=0 | 257 | +10/−1 | 0.0117 | 3.1604 |
| λ=0.05 | 261 | +14/−1 | 0.00098 | 2.8514 |
| λ=0.1 | 256 | +12/−4 | 0.0768 | 2.4602 |

**臂间配对全部不显著**（λ0 vs λ0.05 p=0.388；λ0 vs λ0.1 p=1.000；λ0.05 vs λ0.1 p=0.180）。逐甲 Spearman(Δ抖动, ΔboundaryIoU) = +0.005 / −0.034 / −0.021 ≈ 0。

- §9 的「反证」原文要求抖动降到 ≤0.5px 才判「不是瓶颈」。实际只压到 2.46px，但**同向证据更强**：λ=0.1 压掉 22.2% 抖动后联合**没有**任何相对 λ=0 的变化（p=1.000），且逐甲层面抖动降幅完全不预测指标变化。因此判定为**「抖动不是瓶颈」成立**，路线终止；把 λ 推到 0.5 量级需付原目标 ~14% 代价并进入甲尖磨圆风险区，收益无证据支持，不再做。
- 唯一可复用的正结论：**续训本身有真实但很小的增益**（λ=0 臂不碰抖动也 +9，p=0.0117）。这属于「多训一轮」而非本方案贡献，且 248→257 距 539 门仍远。
- S5 未触发。运行时 `radiusSmoothing` 保持关闭。白皮书 v1.2.324 已登记该负结论。
