# 甲如美甲纹理正式模型目标

更新日期：2026-10-20
状态：ACTIVE / PRODUCT HOLD

## 目标

交付可商用、在浏览器本地运行并接入 /ar-tryon 的正式模型：每枚完整可见、边界可确认的甲面输出且只输出一个可映回原图的完整像素级 mask，可直接提取美甲纹理。

下一轮唯一里程碑：按cycle016-runtime-trace-v1/next-capture-requirements.json实现原完整图的参数/缓冲身份跟踪：先验证实际JS执行分支、补丁逆变换与日志/资源上限，再冻结WASM/WebGPU各9；完整36原最终头逐字节保真、初始化及九次运行日志完整后，才判断操作数来源或生命周期冲突。缺项或保真失配拒绝归因，不重启旧预算。

## 核心要求

- 模型找不到甲面、甲缘不可确认或只有 MediaPipe、颜色、矩形等辅助定位时，产品必须提示人工确认，不能算正式识别成功；不得把裁边、遮挡、严重失焦甲面强行计入可自动抠图队列，也不得因模型漏检移出已锁定真值分母。
- 训练素材虽已获商业使用授权，仍须逐图核对完整甲面、完整 mask、多边形合法性、同图零交叠、来源组与数据角色。已消费 val/test/holdout 及派生物不回训。按2026-10-12用户明确指示，正常开发训练保留原图角标，暂缓角标处理及消融；仅闭合清晰度、完整真值及保护角色并排除来源关系未决整组的清单可用于本开发训练，不自动获得正式来源独立或发布资格。角标变体及新模型捷径消融仍须在正式发布前闭合，旧失败与隔离不改写。
- 开发按预注册、可证伪合同执行，先核验真值、角色和可达性，再消费训练/推理预算；事前写明假设、完整分母、产物、预算与继续/停止条件。开发评估用途必须冻结，不把既有train改成未见评估，不消费正式校准/发布留出用于试错；参与选择的开发证据不再冒充未见发布证据。达到预算或假设被证伪即结项，另有新依据才开新分支，不重启已消费预算。
- 正式阈值只用新来源隔离 val≥30 校准一次；锁定同一 releaseIdentity 后使用新来源隔离正样本发布留出≥100，要求实例召回≥0.90、完整 mask 比例≥0.85、漏甲图率≤0.10、加权杂散率≤0.02；另有新困难负样本≥100及原图、裁右下12%、模糊右下角三变体零误检门。
- 运行时修复沿用原两头绝对1e-4、解码零像素差及presence决策门，不修改权重、mask或原严格参考来过门。同时验证实际部署尺寸、下载/初始化、端到端P95、完整流程峰值内存与重复运行稳定性，按实施规范§13及设备合同验收；数值通过不能代替边界质量或端侧可用性。
- 生产 ONNX、浏览器及四类移动设备各≥20次有效运行、Beta人工审核≥100张、产品质量和两个不同批准权重的回滚演练，均须绑定同一发布身份。只有 completion audit v3 对全部当前发布门返回 ok=true、decision=complete，才可解除 HOLD 并标记 Goal 完成。
