# 甲如美甲纹理正式模型目标

更新日期：2026-09-10
当前状态：`ACTIVE / PRODUCT HOLD`

## 目标

交付可商用、在浏览器本地运行并接入`/ar-tryon`的正式美甲纹理识别模型。模型必须为每枚完整可见甲面输出且只输出一个可映回原图的完整像素级mask，并可直接用于纹理提取。模型不可用或只有MediaPipe、颜色、边界、矩形、椭圆等辅助区域时，产品必须显示“辅助定位、需要人工确认”，不得计入正式识别成功率或Beta直接可用率。

本轮活动目标：向用户提交循环013**可达性前置判决**及五项待决策（A 原型去留、B 开发评估集规模、C 产品是否必须全自动识别、D 素材供给产能、E 是否把训练吞吐诊断结论`workers: 0→8`写入下一份预注册计划），在裁决前不启动任何训练、物化或推理，训练启动门保持关闭。判决依据为2026-09-10零推理只读分析：clean98上21枚漏甲中**仅5枚**存在可附着候选、**16枚按构造无候选可替换**；即便假设stage2成功率100%并对每枚可附着候选替换为其附着真值的完美mask，漏甲图也仅13→11（门≤5）、加权杂散率`0.0960452`→`0.07627119`（门≤0.02），双轴同时不达标（`unreachable_by_mask_replacement_stage2`）；且现58张正图规模下漏甲图率的相对门落在Wilson噪声内（13/58的95%区间[0.13594,0.34661]覆盖10/58，同分母最小可判别差`0.14480`大于实际差0.05172）。
