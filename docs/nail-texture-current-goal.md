# 甲如美甲纹理正式模型目标

更新日期：2026-10-11
状态：ACTIVE / PRODUCT HOLD

## 目标

交付可商用、在浏览器本地运行并接入 /ar-tryon 的正式模型：每枚完整可见、边界可确认的甲面输出且只输出一个可映回原图的完整像素级 mask，可直接提取美甲纹理。

下一轮唯一目标：从候选原序queue100（db43fba3…目标与0fa11ce3…受保护已消费测试原图）起，按实际记录固定下一最多3对、分别绑定两端来源/角色/父血缘并验完整旧查看证据，补首个缺口；精确身份重复只查看一次，旧图只继承内容、不重发、不继承旧图对结论。源原编码/RAW/原尺寸/全页覆盖验真后逐张发送，单页文件及实际载荷≤1MiB、每轮新增≤4MiB，完整请求另采且百MB级停止；全批旧证据齐备才允许≤12纯继承。来源复用整组隔离，源质处置保持原角色/真值/失败及全部分母；待标注候选完整mask与来源标记门通过前禁止训练。

## 核心要求

- 模型找不到甲面、甲缘不可确认或只有 MediaPipe、颜色、矩形等辅助定位时，产品必须提示人工确认，不能算正式识别成功；不得把裁边、遮挡、严重失焦甲面强行计入可自动抠图队列，也不得因模型漏检移出已锁定真值分母。
- 训练素材虽已获商业使用授权，仍须逐图核对完整甲面、完整 mask、多边形合法性、同图零交叠、来源组与数据角色。已消费 val/test/holdout 及派生物不回训；水印须登记并完成变体及模型捷径消融。未通过前训练用途禁止。
- 开发只验证预注册的可证伪变量；全 split 真值和角色审核、train-only 可达性/微拟合门通过后，完整跑满30轮再统一选 best。正式阈值只用新来源隔离 val≥30 校准一次；锁定同一 releaseIdentity 后使用新来源隔离正样本发布留出≥100，要求实例召回≥0.90、完整 mask 比例≥0.85、漏甲图率≤0.10、加权杂散率≤0.02；另有新困难负样本≥100及原图、裁右下12%、模糊右下角三变体零误检门。
- 生产 ONNX、浏览器及四类移动设备各≥20次有效运行、Beta人工审核≥100张、产品质量和两个不同批准权重的回滚演练，均须绑定同一发布身份。只有 completion audit v3 对全部当前发布门返回 ok=true、decision=complete，才可解除 HOLD 并标记 Goal 完成。
