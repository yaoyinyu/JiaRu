# 甲如美甲纹理正式模型目标

更新日期：2026-09-25
当前状态：`ACTIVE / PRODUCT HOLD`

## 目标

交付可商用、在浏览器本地运行并接入`/ar-tryon`的正式美甲纹理识别模型。模型必须为每枚完整可见甲面输出且只输出一个可映回原图的完整像素级mask，并可直接用于纹理提取。模型不可用或只有MediaPipe、颜色、边界、矩形、椭圆等辅助区域时，产品必须显示“辅助定位、需要人工确认”，不得计入正式识别成功率或Beta直接可用率。

本轮活动目标：在隔离原图上返修分片003序号49的第3/4/5枚旧mask，并对五枚完整甲面做原像素终审；来源标记另登记四变体与未来模型消融债，不以几何通过代替视觉批准。

## 核心要求

- 512方形letterbox、产品去重和单阶段YOLO仍为冻结对照。MediaPipe只可生成待验证ROI，辅助ROI不得计为正式识别结果；定位失败转人工确认，禁止复活固定网格兜底。
- 每轮只验证一个可证伪假设，在train内按`sourceGroup`使用互斥开发折，至多运行两个短程单变量实验；禁止同输入原样重训、使用正式发布集调参或连续扫描微小阈值。
- 训练图片必须具备商业训练授权，并通过原分辨率源图、完整甲面mask、多边形合法性、同图零交叠和数据角色隔离审核。裁边、严重模糊或无法确认完整轮廓的正图不得训练。
- 正式识别队列只接纳完整可见且轮廓可确认的甲面；残缺、触边、严重遮挡或轮廓不可确认甲面应在候选资格层拒绝并交给人工流程，不得强行输出或计为成功。锁定真值中已经确认完整可见的甲面不得因模型漏检而移出分母。
- 水印图允许进入train，但水印不得进入甲面mask；必须登记水印位置和类型，并完成去除、遮挡、模糊及位置变化消融，证明模型没有学习水印捷径。
- 配方锁定后流程：建立不少于30张全新来源隔离校准集，只校准一次阈值；随后冻结权重、512预处理、阈值、后处理和唯一`releaseIdentity`；使用不少于100张全新来源隔离正样本发布留出进行一次正式评估，要求实例召回率≥0.90、完整mask比例≥0.85、漏甲图片率≤0.10、加权杂散率≤0.02；候选锁定后建立不少于100张全新未见困难负样本，部署512下原图、裁右下12%、模糊右下角均须误检图片数=0、误检检测数=0、相对原图delta=0，其他位置水印增加对应变体。
- 发布证据必须绑定同一`releaseIdentity`，禁止跨候选拼接：生产ONNX、manifest、训练框架、WebGPU、WASM、浏览器、桌面、四类移动设备（分别至少完成20次有效运行）、Beta人工审核（不少于100张）、产品质量，以及两个不同权重且完整批准版本的回滚建立与实际演练。
- 现有项目图像和本机计算资源可按standing授权直接用于商业模型开发；清单、来源、许可、角色和SHA-256仍须记录。已消费val/test/holdout及其派生物不得回流训练。
- 只有completion audit v3对同一`releaseIdentity`的全部当前发布门重放为`ok=true`且`decision=complete`，才允许解除产品HOLD并标记目标完成。
