中国版权保护中心自 2026-03-15 起启用新版申请表，旧版不予受理。三项关键变化：

1. **签章页须经办人亲笔手抄**（黑色中性笔，严禁打印/代签/涂改），并签名 + 填身份证号：

2. **「软件主要功能/技术特点」从「200 字以内」提升到 500—1300 字**，须完整说明研发背景、核心架构、功能模块、技术实现与应用场景；严禁模板化、AI 批量炮制。
3. 四类"非正常登记"从严审核：批量突击申请、软著技术方向与业务逻辑不符、源代码拼凑/重复申报、**提交 AI 生成的模板化申报材料**。

### 1.3 风险（必须如实告知，不可绕过）

本项目从模型训练到白皮书编写，**大量环节由 WorkBuddy / Codex 等 AI Agent 参与开发**（见 `dev-log/` 各条署名）。如实签署上述"未使用 AI 开发编写代码、撰写文档"声明存在失实风险，代价为列入失信名单 + 个人征信记录。

这是需要**申请人本人**决定并向中国版权保护中心或专业代理核实的合规问题，不是可以在技术层面消解的问题。本备忘录不代拟、不代写、不代签该声明。

### 1.4 建议做法

1. **先核实**：由本人向版权中心或持牌代理核实"AI 辅助开发"在"人的独立开发"语境下的认定口径（建议以书面答复为准）。
2. **文档必须本人撰写**：500—1300 字功能说明及手抄声明段落由本人完成，不由 AI 生成。
3. **申报主体选择**：
   - 个人：身份证 +《非职务开发证明》/《非职务开发保证书》
   - 公司：营业执照副本复印件 + 公章（若已有/计划设立公司主体，建议以公司名义申报，便于后续高企/双软/项目申报）
4. **时序**：软著无"必须等产品上线"的要求，代码已稳定固化在载体上即可申报。但建议在上述合规问题核实后再提交，避免返工。

## 2. 发明专利

### 2.1 大方向已被现有技术覆盖（这是主要障碍）

| 现有技术 | 覆盖内容 |
| --- | --- |
| CN106127181B | 虚拟试美甲方法：肤色模型分割 → 分类器/纹理特征模态分类 → 轮廓特征点 → 指尖/指根定位 → 甲区佩戴特征 → 融合试戴 |
| US11393089 / US20230005137 | AR 指甲检测与追踪：帧内指甲区域检测 → 帧间基于相机/手指移动的追踪 → AR 覆盖渲染 → 预约闭环 |
| CN116645492A | 基于 AR 眼镜的美甲辅助方法：实时手部姿态数据 + 渲染美甲图案至指甲区 |
| CN122250740A | 深度学习甲面识别 + 空间定位（美甲固化设备场景，含实时试戴） |

因此「**AR 美甲试戴 + 指甲识别 + 纹理贴合**」作为整体布局已被密集覆盖，直接提交大概率被驳回，或只能拿到保护范围极窄、无法实际维权的授权。

### 2.2 收窄后确有新颖性的技术点

**（1）固定可编辑带内的受约束残差精修**
源码：`model/training/native-boundary-nail-refinement.py`
- 六通道输入：ImageNet 归一化 RGB + 冻结基底概率 + 同候选粗 mask + 固定 4 像素可编辑边界带
- 输出层零初始化；合成时 `torch.where(band, baseline + delta, baseline)` —— `delta` 的梯度**只存在于带内**
- 推理时带外概率**逐 bit 保留**（而非近似保留）
- 可主张：在既有分割基底的甲缘邻域引入受约束的低维残差修正，使带外像素结果严格不变，从而避免重训主干导致的整体退化

**（2）同候选粗 mask 条件化的双路径精修**
源码：`model/training/native-dual-path-nail-refinement.py`、`model/training/conditional-nail-refinement-model.py`
- 第 4 通道为**同一候选**的粗 mask；空间局部路径（7px 感受野）与上下文路径（27px）残差相加
- 预训练语义骨干的**三通道合同保持不变**，条件信号只经空间分支进入融合网络
- 独立 `fork_rng` 固定局部路径初始化，不污染外部随机流与 CUDA 状态
- 另含双向多尺度融合（top-down + bottom-up）与独立 boundary tower

**（3）配对变体的模型捷径归因方法**
源码：`model/training/run-variable-train-role-marker-probe.py`
- 9 个确定性变体：原图 / 标记移除 / 空白移除 / 标记遮挡 / 空白遮挡 / 标记模糊 / 空白模糊 / 标记移动 / 空白移动
- 8 组**受控配对**：其中 `marker_removed↔blank_removed`、`occluded↔occluded`、`blurred↔blurred`、`moved↔moved` 构成"有标记 vs 无标记"的配对对照
- 每变体恰好一次推理，原像素预测持久化，重放不再推理
- 分母合同强制完整来源组纳入
- 可主张：通过受控变体配对消融，判定分割模型是否依赖非语义捷径（角标/水印/贴纸）

**（4）发布级三变体零误检门**
原图 / 裁右下 12% / 模糊右下角，部署 512、固定阈值、确定性生成，三变体须零误检。

### 2.3 必须正视的法律与策略风险

**（a）专利法第 25 条：智力活动的规则和方法不授予专利权**
尤其第（3）项方法论，若写成抽象规则极易被认定为"智力活动方法"。必须写成"作用于图像像素数据、产生像素级掩码输出的技术手段"，以技术特征而非规则表述权利要求。

**（b）实施例的技术效果缺乏实测支撑 —— 这是当前最大的实质障碍**
白皮书 §3/§11.1/§12.240 与 Goal 文件明确记载：正式模型处于 **PRODUCT HOLD**，生产 ONNX 为 0，完整 30 轮未启，candidate57 仍为 **TEST HOLD**；循环 016 固定 32 例 train 调权微拟合联合率 0.40625，未过 0.80 门。
即：上述精修路线**目前均未通过质量门**。专利说明书虽不强制提交实验数据，但"技术效果"主张需要可复现的实测支撑。**建议在正式模型真正通过门、产生可量化提升之后，再提交机制类（1）（2）**；或仅主张有代码与实验日志支撑的部分。

**（c）先申请后公开是不可逆的硬纪律**
本仓库目前为**私有**（`https://github.com/yaoyinyu/JiaRu` 返回 404），未构成公开披露，新颖性完整保留。

中国专利法第 24 条仅在三种情形给予 6 个月宽限期：在中国政府主办或承认的国际展览上首次展出、在规定的学术会议或技术会议上首次发表、他人未经同意泄露。**主动公开不在宽限期内。**

因此，一旦发生下列任一情形，对应方案的专利新颖性即永久丧失：
- 发表论文或在会议/讲座中公开方案
- 开源仓库
- 产品上线、对外演示、媒体报道
- 申请人在社交平台披露技术细节

**当前仓库私有是本项目最大的战略资产，不要为展示而开源。**
