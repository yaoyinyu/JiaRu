# 新拟态风格提示 — 甲如

用于项目页面或组件实现时的精简提示。完整约束以 [UI设计规范](ui-design-spec.md)为准；正式站与独立消费者预览分别使用各自样式令牌和设计方案。历史通用灰底／紫色示例由项目品牌适配替代。

## 可复用提示

```text
在甲如现有设计系统中完成本次页面或组件任务。

先读 UI 设计规范及本次适用的设计方案，核对当前源码与白皮书状态。
复用项目米白／珊瑚令牌、已加载字体和共享组件。

1. 用留白、字体与少量图形建立层级，突出主要任务和动作。
2. 交互结构采用同色系双阴影：左上亮、右下暗；图片、画布和色卡采用平涂，周边保留中性间隔。
3. 新拟态按钮 hover 收小外阴影，active 转为 inset；输入框 focus 减浅内阴影，并保留可见焦点。
4. 使用当前组件的圆角、时长和缓动令牌；显式列出过渡属性，提供 reduced-motion 处理。
5. 对比度、键盘操作和触控目标先满足 UI 规范；图标入口具备可访问名称，状态提供文字或图形提示。
6. 完整处理加载、空态、失败、取消及恢复；删除按流程提供确认或撤销。
7. 保持图片与甲油内容色；技术诊断按需展开，产品文案对应实际能力。
8. 按本次改动检查响应式、缩放、焦点、IME、安全区和软键盘，并如实记录验证范围。
```

## 使用与维护

- 把具体页面、组件或状态需求附在提示后；已有功能与交互合同优先按当前实现核对。
- 普通按钮遵守无浮起位移约定；开关滑块、画布拖动等功能运动遵守各自合同。
- 内容区中性或纯白底、摄像头覆盖层、细边框及高对比焦点按 UI 规范的用途配置。
- 令牌、交互规则与验收要求只在 UI 规范及相应实现中维护；本文件保持短提示，避免重新堆叠互相冲突的示例和禁止清单。
