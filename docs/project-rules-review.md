## 2. 发现与修订

| 发现 | 修订 | 核验依据 |
| --- | --- | --- |
| 规则入口缺少开发/UI规范路由；读取依赖散落在表后 | 扩充读取矩阵，在专项文件增加依赖链接和主题分组 | 根规则、六份专项与现有规范文件 |
| 根规则与专项分散维护本机执行细则，白皮书重复生命周期摘要 | 命令细则集中在开发专项，根规则保留引导；明确白皮书摘要与规则归属 | AGENTS及白皮书§1 |
| TEMP/TMP一律要求仓库内，与发布测试工作区守卫冲突 | 按测试输出合同选择可写隔离目录；全量测试同时满足仓库外守卫和环境权限 | `build-release-test-annotation-workspace.py`的`require_outside_repository`、对应测试及当日日志 |
| 将exit 1、固定内存值和worker数写成通用根因判断 | 改为采集日志、进程归属、内存与当前配置后判断；限定停服对象 | 开发专项原条款、当前package与本机执行规则 |
| 开发规范要求小步提交、只发送文字，并回避effect状态依赖 | 提交引用显式授权；隐私按实际路由数据流；effect按响应式依赖和Hooks lint处理 | AGENTS、`generate-ai/route.ts`、`agnes-image-api.ts`、`nail-matte/route.ts`、ESLint及Hooks插件 |
| 组件命名、目录和浏览器版本承诺沿用旧约定 | 按当前源码组织与配置校正；兼容范围由功能检测及验收证据支持 | `src/components/`、`src/lib/`、`tsconfig.json`、`package.json` |
| UI规范仍为玫瑰粉，长风格提示含冲突的聚焦阴影、颜色与过渡要求 | UI规范对齐现行品牌与交互合同；提示词精简、引用令牌；维护下游历史偏差引用 | `globals.css`、产品设计方案、交互改造方案、消费者预览简报 |
| Goal模板要求每轮改写活动目标，且重复一套治理规则 | 完成、证伪或路线调整后切换；未闭合活动保留；治理流程引用AGENTS | AGENTS§3.3、白皮书§9.10及当前Goal结构 |
| 现行整图要求与历史裁片/并排页操作混在同一节 | 三条历史页规则移至独立解释小节，保留原条文 | 视觉专项首部输入规则及历史坐标保真条款 |
| README规则入口不完整，白皮书版本副本过期 | 补规则导航，版本统一查白皮书头部 | README文档索引及白皮书v1.2.213 |
