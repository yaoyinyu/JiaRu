## 1. 统一动效语言（风格统一基础）

### 1.1 Token：既有（不动）与新增（本方案提出）

既有 Token（`style.css :root`，继续作为唯一事实源）：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(.22,.7,.2,1)` | 通用快捷曲线（水波、液态、微交互） |
| `--ease-soft` | `cubic-bezier(.4,0,.2,1)` | Smooth Molding 标准曲线 |
| `--dur-soft` | `.3s` | Smooth Molding 标准时长 |
| `--ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 过冲回弹（磁吸吸附） |

### 1.2 六条统一原则

1. **原地弹性，无静态位移**：所有形变只用 `scale`／`rotate`；禁止按钮类元素的 `translate` 位移（硬 prompt 禁止项，新拟态元素长在背景上）。例外仅两类且均为交互过程而非静态态：跟手拖拽与抛出（§2.11）、数字列容器内部滚动（§2.7），实施时按 §5 登记偏差。
2. **光源锁定，阴影不形变**：双光源方向（左上亮／右下暗）全局锁定；squash & stretch 只作用于元件本体，阴影永远按 Token 整组切换，不跟随缩放、不扭曲、不变向。
3. **反馈跟随指针**：水波、爆散的原点一律为指针落点（换算到控件坐标），不是控件几何中心；键盘触发时取控件中心。
4. **物理语言统一**：只有两种物理——过冲回弹（spring，`--ease-spring` 过冲系数 1.56，全项目共用同一过冲幅度）与挤压拉伸（squash & stretch，体积近似守恒）。不混用第三种手感。
5. **同频一致**：联动元件（开关的轨道／滑块／填充，液态滑杆的填充／滑钮／隆起，堆叠卡的前卡／后卡组）共享同时长、同曲线、同起始帧；优先用单一驱动（CSS 自定义属性过渡或同一帧写入）从结构上排除不同频。
6. **降级一致**：`prefers-reduced-motion` 下全部动效瞬时或静态等价，功能与状态语义不损失；WAAPI／IntersectionObserver／`@property` 缺失时退回 CSS class 过渡或静态终态（延续既有 capability 检测模式）。

### 1.3 与既有规范的偏差登记（实施时同步写入简报新增章节）

本方案以下四条与简报 §8.3／硬 prompt 当前口径存在有意偏差，实施时按简报 §8.4 惯例逐条登记（旧值、新值、原因）：

1. **按压回弹重新引入 `scale`**：简报 §8.3 曾移除「脚本缩放按压（`pointerdown` 的 `scale(.97)`）」。差异：旧实现是一次性简单缩放；本方案是「下沉 → 越过原始尺寸过冲 → 回弹落位」的三段重量感动效，且 `scale` 不属于 `translate` 位移，不破坏「元素长在背景上」的语义。原因：用户明确要求体现重量感。
2. **卡片抽走与跟手拖拽引入 pointer 驱动 `translate`**：仅存在于抓取—抛出的交互过程，静态态任何元素无位移；属交互物理而非悬停抬升（简报 §8.3 已移除位移悬停，本项不恢复悬停位移）。
3. **数字滚动在列容器内部使用 `translateY`**：滚动发生在固定行高的溢出容器内，非页面元素位移，不产生布局抖动。
4. **爆散粒子与骨架 shimmer 使用珊瑚系柔光**：硬 prompt 禁止的是渐变背景与高对比配色；反馈层粒子／柔光统一取 `--coral`／`--coral-soft`／`--sage` 低透明，纸底上已按既有对比度口径校准，不构成渐变背景或高对比漂移。

## 2. 十一项交互动效规格

每项含：动效目标、动效说明（分镜）、关键参数表、实现要点、降级与边界。

### 2.1 按压回弹（过冲回弹的重量感）

**动效目标**：按压时控件被「压进去」（转凹陷＋轻微缩小），松手时先越过原始尺寸再回弹落位，呈现软塑料／有重量物体的惯性；不是一次性简单缩放还原。

**动效说明**（三阶段）：

1. 按下（0–140ms）：`box-shadow` 由凸起转凹陷（既有 Extrude to Intrude），`transform: scale(.96)`，`--ease-press` 减速进入——模拟手指逐渐压实的吸入感；
2. 回弹（140–480ms）：释放瞬间从 `scale(.96)` 以 `--ease-spring`（340ms）过渡回 `scale(1)`；因曲线过冲系数 1.56，实际路径 `.96 → 1.025 → 1`，即越过原始尺寸约 2.5%（72px 控件约 1.8px）后回落；
3. 阴影同步：凹陷→凸起的阴影过渡使用同一曲线与同时长，形状回弹与光影回弹同帧同频。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 按压缩放 | `.96` | 全局统一（原 `.92` 仅开关滑块保留，见 §2.2） |
| 过冲幅度 | ≈ +2.5%（1.6–2px） | 由 `--ease-spring` 过冲系数决定，不逐控件调 |
| 按下时长 | 140ms（`--dur-press`） | `--ease-press` |
| 回弹时长 | 340ms（`--dur-rebound`） | 与开关滑块同档 |
| 阴影过渡 | 340ms `--ease-spring` | 与 transform 同时长同曲线 |
| 中断策略 | 取消未完成回弹，从当前 computed 值重播 | 禁止两次回弹叠加大缩放 |

**实现要点**：

- `:active` 与脚本双通道：CSS `:active` 承担凹陷兜底（无 JS 仍可用）；脚本仅在释放后播放一次性三段回弹（WAAPI 关键帧 `scale(.96) → scale(1.026) → scale(1)`，`duration:340`，`easing:'cubic-bezier(.34,1.56,.64,1)'`，fill `none`），不依赖 `:active` 移除时序；
- 中断：回弹未完成时再次按下，先 `getAnimations().forEach(a => a.cancel())`，再以 `getComputedStyle(el).transform` 为首帧重播；
- 键盘路径：keydown 播按下、keyup 播回弹，与指针同参；
- 只动画 `transform` 与 `box-shadow`；阴影整组按 Token 切换，不参与 squash（原则 2）；
- 应用范围：主／次按钮、chip、图标钮、模式卡 CTA、保存钮；不用于开关滑块（滑块有独立弹性语言）。

**降级与边界**：`prefers-reduced-motion` 下无 scale、无过冲，仅 `:active` 内凹瞬时切换（既有行为不变）。偏差登记见 §1.3 第 1 条。

### 2.2 弹性开关滑块（起步横拉、落位压回）

**动效目标**：滑块起步时沿运动方向被「拽长」（横长纵窄），过冲后落位瞬间压回原宽，体现橡皮筋弹性；阴影全程不畸变。

**动效说明**（以关→开、向右运动为例；开→关为镜像）：

1. 起步（0–120ms）：滑块 `translate(0→9px)` 同时 `scaleX(1→1.24)`、`scaleY(1→.88)`，`transform-origin: left center`（右侧被拽着走）；
2. 过冲（120–240ms）：继续右移越过终点 22px 至约 24px（spring 曲线提供过冲）；
3. 落位（240–340ms）：回到 22px，`scaleX` 从 1.24 压回 1（末段含 30ms 微反向挤压至 .97 再回 1，表达「吸附压实」），`scaleY` 同步回 1；origin 回 center；
4. 轨道珊瑚填充在滑块起步 40ms 后开始、340ms 同曲线完成——滑块「先探身」，填充跟进。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 位移 | 22px | 既有值不变（宽 52 − 滑块 24 − 2×3px 内偏距） |
| 起步拉伸峰值 | `scaleX 1.24`／`scaleY .88` | 体积近似守恒（1.24×0.88 ≈ 1.09） |
| 拉伸段时长 | 约 120ms（总时长 35%） | 起步即拉伸，中段前完成 |
| 过冲 | +2px | 与 `--ease-spring` 过冲一致 |
| 落位压回 | 约 80ms | `scaleX 1.24→1`，含 30ms 微反向挤压 |
| origin | 起步跟方向（左／右），落位 center | 方向感锚点 |
| 阴影 | 全程 `--neu-out-sm` 不变 | 形变不碰阴影（原则 2） |
| 总时长 | 340ms，`--ease-spring` | 轨道／滑块／填充三者一致 |

**实现要点**：

- 用 WAAPI 多关键帧（分段 easing）表达「起步拉伸＋过冲＋落位压回」；单一 CSS transition 无法实现非均匀形变。反向运动用镜像 keyframes，origin 随方向切换；
- 按住不放保留既有 `.switch-row:active::after` 的 `scale(.92)` 整体收缩，与位移形变叠加时保证 transform 组合顺序（先位移后形变）；
- 快速来回切换：cancel 进行中动画，从当前 computed transform 重播新方向 keyframes；
- 验收以 `getAnimations()` 实证：滑块位移为运行中的 spring 过渡（延续复选框套件 C8t 口径），且形变段 `scaleX > 1`、阴影 token 未变。

**降级与边界**：`prefers-reduced-motion` 下仅 `translate(22px)` 过渡（既有），无 `scaleX/scaleY` 形变。四处开关（试戴、偏好、发布、轻问答）行为一致。

### 2.3 水波按钮（指针原点扩散）

**动效目标**：以指针落点为原点的径向柔和水波，反馈跟随手指而非控件几何中心；铺满控件前开始淡出，边缘无硬切。

**动效说明**：

1. `pointerdown` 即在控件内插入水波层，圆心＝落点（`getBoundingClientRect()` 换算为控件内坐标），初直径 0；
2. 水波 `scale(0→1)` 扩散至覆盖整个控件（直径＝2×落点到最远角欧氏距离），同时 `opacity(.30→0)`；淡出在扩散完成约 70% 时启动；
3. 扩散结束移除 DOM；连点可叠加多个水波（各自独立播完）。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 原点 | 指针落点（±1px） | 键盘触发取控件中心 |
| 半径 | 落点到最远角距离 ×1.02 | 保证铺满无死角 |
| 时长 | 480ms（`--dur-ripple`） | `--ease` |
| 峰值不透明度 | .30（纸底控件）／.22（墨底主钮） | 双色板 |
| 填充 | `--coral-soft`（纸底）／`rgba(255,253,248,.22)`（墨底） | 品牌一致 |
| 淡出起点 | 扩散进度 70% | 边缘柔化 |
| 同屏上限 | 每控件同时 3 个 | 超出取消最旧，防连点堆积 |

**实现要点**：

- 控件 `position:relative; overflow:hidden`（圆角裁剪水波）；`overflow` 不影响外阴影绘制，双光源语言不破；
- 水波层 `position:absolute; border-radius:50%; pointer-events:none; will-change:transform,opacity`；
- `pointerdown` 即启动（不等 click，反馈跟手）；`pointercancel` 不撤水波（一旦开始即播完）；
- 与 §2.1 按压回弹叠加：水波是控件内叠层，按压是控件本体 transform，互不干扰；
- 应用：主／次按钮、chip、图标钮、模式卡 CTA、保存钮；不用于纯文本链接与底栏导航（保持导航轻量）。

**降级与边界**：`prefers-reduced-motion` 下不播水波，仅 `:active` 内凹（既有行为）。

### 2.4 关键动作爆散（分量匹配成功）

**动效目标**：关键动作确认成功时从操作原点爆散一次粒子；粒子数量、射程、时长按动作成功分量分档；失败不爆散（「爆散＝成功」单义）。

**动效说明**：

1. 动作进入成功态（收藏确认、方案就绪、发布完成等）时，从指针原点（或控件中心）生成 N 个粒子；
2. 粒子沿径向以初速飞出，阻尼减速，60–70% 时长到达射程峰值后缩小淡出；
3. 全部粒子消失即清理；同屏最多一场爆散，新的取消旧的。

**分量档位**：

| 档位 | 粒子数 | 射程 | 粒径 | 时长 | 配色 | 动作 |
| --- | --- | --- | --- | --- | --- | --- |
| 轻 | 8–10 | 18–28px | 3–4px | 420ms | coral／coral-deep | 收藏、保存、喜欢 |
| 中 | 12–14 | 32–44px | 3–5px | 520ms | coral／coral-text／sage | 方案就绪、分享就绪 |
| 重 | 16–18 | 48–60px | 4–6px | 620ms | coral／coral-deep＋1–2 粒高光星 | 发布完成 |

**实现要点**：

- 每粒独立 WAAPI：`transform: [translate(0,0) scale(1), translate(dx,dy) scale(.2)]`、`opacity: [1,1,0]`；dx/dy 由角度均匀分布＋射程内 ±15% 随机决定；
- 初速 120–220px/s，阻尼使 60–70% 时长达峰值；无重力或 −6px 微上浮（「绽放」语义），与新拟态「软」语言一致；
- 粒子层 `pointer-events:none`，层级高于水波；粒子为圆点，重档含 1–2 粒四芒星高光；
- 节流：同控件 250ms 内不重复爆散；
- 测试模式：随机数可固定种子或关闭（便于回归断言粒子数＝档位值）。

**降级与边界**：`prefers-reduced-motion` 下不爆散，仅状态切换＋toast。语义边界：爆散只表示演示原型内可验证的成功状态（保存成功、方案卡就绪等）；「预览上手结果布局」等演示态保留「示例」标注（简报 §4），不得用于伪造生成成功；失败态禁用爆散。

### 2.5 勾选逐笔绘制（过程感）

**动效目标**：勾选状态以描边路径逐笔画出（落笔—行笔—收笔），呈现书写过程感；容器选中态与笔画同频完成。

**动效说明**：

1. 选中瞬间对钩路径从 0 开始绘制：`stroke-dashoffset 100→0`（`pathLength="100"` 归一化）；
2. 起笔段（0–30% 时长）稍慢模拟落笔，中段加速，收笔段（70–100%）放稳；
3. 容器选中态（coral-soft 底＋inset 凹陷）与笔画同刻开始、300ms（`--dur-soft`）完成；
4. 取消选中：反向擦除（`dashoffset 0→100`）200ms，快于绘制，表达撤回。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 笔画时长 | 280ms | 起笔慢、收笔稳 |
| 曲线 | `cubic-bezier(.65,0,.35,1)` | 两段感知：起 30% 慢、收 30% 稳 |
| 容器态过渡 | 300ms `--ease-soft` | 既有选中过渡 |
| 擦除时长 | 200ms | 快于绘制 |
| 线宽／线端 | 2px，round cap／join | 44px 触控目标内清晰 |
| 颜色 | `var(--coral)` | 纸底上 4.76:1，达图形 3:1 门 |

**实现要点**：

- 单 `<path pathLength="100">`＋CSS `stroke-dasharray:100; transition:stroke-dashoffset 280ms`（或 WAAPI 补间）；对钩几何 `M6 12.5 L10.5 16.5 L18 7.5`（24 viewBox），起笔左下、收笔右上；
- 对钩图标常驻 DOM，仅 `dashoffset` 变化——不插入／移除节点，避免布局跳动；
- 应用位置：偏好清单、方案选择卡、开关选中提示等新增选择控件；不替换既有 chip 选中语义（chip 维持凹陷＋soft 底＋deep 字）；
- 对钩不承担唯一选中语义：选中同时有底色、凹陷、文字色三重冗余。

**降级与边界**：`prefers-reduced-motion` 下直接完整显示（`dashoffset:0`，无过渡）。

### 2.6 液态滑杆（轨道、滑钮与竖直动画同频）

**动效目标**：轨道填充、滑钮位移与竖直方向液面隆起共享同一条时间轴与同一曲线，视觉为一个整体联动；跟手期零延迟，吸附档位过冲定位。

**动效说明**：

1. 值变化（点轨道／键盘／吸附档位）：填充宽度、滑钮位置、液面隆起同时启动，400ms 同曲线；
2. 竖直耦合：滑钮处液面随位移隆起（`scaleY 1→1.18`，`transform-origin:bottom`），与滑钮同起同落；松手后 280ms 回落；
3. 拖动跟手期：填充与滑钮实时跟随指针（`transition:none`），被捏住的滑钮 `scale(.94)`；松手吸附时恢复过渡并以 spring 过冲定位（与开关同语言）。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 值过渡 | 400ms，`--ease-liquid` | 填充／滑钮／隆起共用 |
| 隆起峰值 | `scaleY 1.18`，origin bottom | 竖直耦合量 |
| 隆起回落 | 280ms `--ease-soft` | 松手后 |
| 跟手期 | `transition:none` | 拖拽中零延迟 |
| 吸附过冲 | 1.5–2px，340ms spring | 与开关同档 |
| 抓取缩放 | `.94` | 被捏住感 |
| 档位 | 4–5 个刻度，吸附阈值 ±8% | 演示结构 |

**实现要点**：

- 同频硬实现：`@property --v { syntax:'<number>'; inherits:true; initial-value:0 }`，滑杆根节点过渡 `--v`（400ms 同曲线），填充宽度、滑钮左距、隆起 `scaleY` 全部由 `calc(var(--v))` 派生——从结构上排除不同频；
- 旧浏览器降级：三条 transition 同时长同曲线，并在同一同步代码块内写入（避免读-写-读抖动）；
- 验收：`getAnimations()` 断言三条动画 `startTime`／`duration`／`easing` 一致（或 `--v` 单过渡）；
- 结构：胶囊凹陷轨道（`--neu-in-sm`）＋珊瑚填充＋凸起滑钮（`--neu-out-sm`），圆角一律 `--radius-capsule`（简报 §8.8）。

**降级与边界**：`prefers-reduced-motion` 下无隆起，值过渡瞬时。滑杆为原型新增演示控件（长度／宽度／强度校准展示），数值不写入任何训练或发布契约。

### 2.7 数字滚动（缓动减速自然停止）

**动效目标**：数字变化时各位逐位滚到新值，强减速自然停止（末段速度趋零），高位后停形成层次；无生硬跳变。

**动效说明**：

1. 新值到达：低位先启动、高位延迟 80ms 启动，逐位安定；
2. 每位沿竖直列从当前数字滚到目标数字——数值增大向上滚、减小向下滚（机械轮盘惯例）；
3. 末段强减速自然停止；滚动中的数字可选 30% 动态模糊（`blur .4px→0`）增强速度感，性能敏感场景省略；
4. 连续变化（计数进行中）：取消上一位未完成动画，从当前 computed 值续滚。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 基础时长 | 320ms（低位） | 位序每高一位 +100ms（420／520ms） |
| 位序延迟 | 80ms／位 | 低位先滚 |
| 曲线 | `--ease-roll` `cubic-bezier(.16,.84,.34,1)` | 强减速，末段趋零 |
| 方向 | 增大向上／减小向下 | 轮盘惯例 |
| 容器 | 每位固定行高＋overflow hidden | 防布局抖动 |
| 短变化 | <100ms 内的连续变化直接跳终值 | 防动画堆积 |

**实现要点**：

- 每位一个 `.digit`（`overflow:hidden`）内嵌 0–9 竖列（可用循环列缩短位移距离），`translateY` 过渡到目标位；
- 千分位、单位、前缀静态，不参与滚动；
- 只动画 `transform`（＋可选 `filter:blur`），合成器友好；
- 应用：我的页统计、方案数量、进度百分比等真实状态值。

**降级与边界**：`prefers-reduced-motion` 下直接换值无滚动。语义边界：数字滚动只呈现真实状态（本地统计、演示计数），不得用于伪造人气／热度数字（简报 §3「无伪造人气数字」约束）。

### 2.8 骨架落位高度契约（高度＝真实内容）

**动效目标**：骨架屏高度与同型真实内容一致（误差 ≤1px），内容到达时交叉淡入淡出替换，替换帧零布局跳动。

**动效说明**：

1. 加载中：按内容模板渲染骨架（图片区／标题／文本／按钮分块），表面一道斜向柔光扫过（shimmer 1.4s 无限，可选）；
2. 内容到达：骨架 `opacity→0`（180ms），真实内容 `opacity 0→1`＋`translateY(8px→0)`（200ms `--ease-soft`），交叉重叠 100ms 无空窗；
3. 骨架保留占位至淡出结束再移除 DOM，防塌陷抖动。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 高度误差 | ≤1px | 同模板同 spacing token 驱动 |
| 骨架淡出 | 180ms（`--dur-crossfade`） | — |
| 内容淡入 | 200ms＋8px 上移 | `--ease-soft` |
| 交叉重叠 | 100ms | 无空窗 |
| shimmer | 1.4s 斜向柔光（可选） | reduced-motion 关闭 |
| 模板 | 卡片／面板／结果三型 | 图片 4/5 aspect、标题两行、文本三行、按钮 48px |

**实现要点**：

- 骨架与真实内容共用同一组布局尺寸（padding／margin／gap／行高），用同一 CSS 变量或同一容器类派生——从结构上保证高度一致，而非逐屏硬调；
- 骨架块圆角与阴影语言一致（凹陷托盘＋纸底），shimmer 取 `--coral-soft` 低透明渐变，禁高对比灰；
- 文本行数按最大分行预设，超出以 `text-overflow` 约束；空态／错误态不骨架，直接替换；
- 验收：同型内容渲染两态，断言骨架 `height` ＝内容 `height`（±1px），替换帧前后相邻元素 `boundingTop` 不变。

**降级与边界**：`prefers-reduced-motion` 下无 shimmer、无位移，瞬时替换。高度契约与动效无关，任何模式下均成立（属布局契约，非动效降级项）。

### 2.9 卡片翻面（正反两面各自隐藏背面）

**动效目标**：3D 翻牌中正面只见正面、反面只见反面，任何角度不穿帮（看不到背面镜像／重影）；翻转可中断反向。

**动效说明**：

1. 点击翻面控件：inner `rotateY(0→180deg)`，520ms，`--ease-soft`；
2. 半程附近可加极轻微 `scale(.99)` 增强「厚度」感（可选）；
3. 半程时正面已背对观众（backface 隐藏）、反面转正显形，两面内容互不闪现；
4. 中途再次触发：从当前角度反向续翻（可中断）。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 时长 | 520ms（`--dur-flip`） | `--ease-soft` |
| 透视 | 1000–1200px | `.flip-card { perspective }` |
| 中段厚度 | `scale(.99)`（可选） | 增强立体 |
| 两面定位 | `absolute; inset:0` | 不占双倍布局 |
| 防穿帮 | 两面均 `backface-visibility:hidden` | 硬门，无例外 |

**实现要点**：

- 结构：`.flip-card(perspective) > .flip-inner(transform-style:preserve-3d; will-change:transform) > .flip-face.front(rotateY(0))` 与 `.flip-face.back(rotateY(180deg))`；
- 禁止用 `opacity` 切换两面（90° 边缘会泄露）；禁止把倒影／阴影画在 face 上（镜像泄露）——倒影放 card 外层且仅正面态显示；
- face 内禁 `position:fixed` 子元素；文字翻转中保持可读，不预先模糊；
- 翻面仅由显式控件触发，不自动翻；翻转中 face 内链接 `pointer-events:none` 防误触（过渡结束恢复）；
- 键盘可聚焦触发（与点击同路径），焦点保持在触发控件上，不因翻面丢失。

**降级与边界**：`prefers-reduced-motion` 下交叉淡入淡出替换两面（180ms `--dur-crossfade`），无 3D。应用：款式详情双面（正面图／背面工艺说明）、方案卡双面（预览／参数）等演示结构。

### 2.10 汉堡图标窄形变换（单一元件连贯过渡）

**动效目标**：汉堡与窄形（关闭 X／窄箭头）之间作为同一组线条元件连续形变，全程用户可追踪元件位置；不出现「一图标消失、另一图标出现」。

**动效说明**（汉堡→X 为主案；窄箭头为次级变体）：

主案（→关闭 X）：

1. 上线 `rotate(0→45°)` 并平移到中心（`transform-origin:center`），240ms；
2. 下线 `rotate(0→−45°)` 平移中心，240ms；
3. 中线 `scaleX(1→0)`＋`opacity→0`，180ms，比上下线早 40ms 开始收——缩短消失而非闪退；
4. 全程按钮自身零 transform（位置锚定），三线始终同批元件。

次级变体（→窄箭头，用于「收起」语义）：中线保留为杆并向左缩（`scaleX 1→.55`，origin left）；上线／下线各旋转 ±45° 并缩短为箭头两翼（origin left），与杆端搭接成尖；240ms 同曲线。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 形变时长 | 240ms（`--dur-morph`） | 既有短过渡档 |
| 曲线 | `--ease-soft` | 全局统一 |
| 错峰 | 中线早 40ms 收 | 40ms 内仍属同一连贯动作 |
| 线宽／线长 | 1.5–2px／16px | 24 viewBox 内 |
| 线端 | round | 与品牌圆角语言一致 |
| 按钮本体 | 零 transform | 位置锚定，用户不丢失位置 |

**实现要点**：

- 单按钮＋单 SVG，三线为同组 path／rect；禁双图标 swap（旧淡出新淡入）与字体图标切换；
- 只动画 `transform`／`opacity`，`top/left` 不参与；`transform-origin` 显式声明；
- `aria-expanded`／`aria-label` 同步切换，2px coral 焦点环保留；
- 同一按钮不同语义（X＝关闭抽屉、窄箭头＝收面板）时形变动画同构，仅目标姿态不同。

**降级与边界**：`prefers-reduced-motion` 下单元件形变保留但瞬时（.01ms），绝不降级为双图标 swap。与既有 `back-link` 箭头的区分：back-link 是导航控件，本项是图标自身在两种姿态间的形变。

### 2.11 卡片抽走时后方堆叠卡片可见

**动效目标**：从堆叠抽走前卡时，后方堆叠卡露出过程可见并跟随前移，堆叠关系在动效中成立；不是前卡消失后后方卡「跳」到前面。

**动效说明**：

1. 抓取：`pointerdown` 前卡进入跟手态（`transition:none`，pointer 驱动 translate＋`rotate` 2–4° 微倾）；同一帧第 2 卡开始向前卡原档位过渡（320ms `--ease-soft`），第 3 卡跟进第 2 卡原档位（+40ms 阶梯）；
2. 越过移除阈值（96px 或 40% 卡宽，满足其一）后释放：前卡沿抛出方向飞出（rotate 增大，末段 opacity 淡出，320–380ms），后方卡继续归位；
3. 未过阈值释放：前卡以 spring 过冲弹回原位（340ms），后方卡同步归位；
4. 归位后阴影随层级同步切换（`out-md→out-sm`，`--dur-soft`）。

**关键参数**：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 层级步进 | `translateY 10px`、`scale .96/.92` | 后卡层深 |
| 归位过渡 | 320ms `--ease-soft` | 与前卡同帧启动 |
| 层间阶梯 | 40ms | 深度感 |
| 抓取微倾 | `rotate` 2–4° | 被捏起 |
| 移除阈值 | 96px 或 40% 卡宽 | 满足其一 |
| 抛出 | 320–380ms，末段淡出 | 沿释放时指针速度向量 |
| 回弹 | 340ms spring | 未过阈值 |
| 堆叠上限 | 3 | 第 4 张起入列表 |

**实现要点**：

- 堆叠容器 `position:relative`，卡 `position:absolute` 叠放；层级差用 translateY／scale／阴影强弱表达，后卡 opacity 保持 1（避免「消失的牌」歧义）；
- 跟手用 `setPointerCapture`，`transition:none`；归位用 class 切换＋CSS transition；
- 移除动作完成才把卡片移出 DOM 与 Tab 序（飞行中保留可聚焦，防焦点丢失）；
- 移除后 toast 说明结果（与既有 toast 一致）；提供撤销入口时，撤销＝前卡反向飞回（320ms）并恢复堆叠；
- 卡片身份以 `look.id` 绑定，堆叠与列表视图切换不重复计数（简报 §4 数据口径）。

**降级与边界**：`prefers-reduced-motion` 下抽走即时移除、后方卡即时归位（无位移），堆叠关系由静态层级差表达。应用：收藏夹／方案列表的堆叠预览卡（演示结构），不接入真实数据删除。

## 3. 降级与无障碍统一口径

- `prefers-reduced-motion`：既有全局规则（`style.css` 媒体查询压制为 .01ms）继续作为总闸；本方案 11 项逐项列明降级行为（见各节「降级与边界」），全部提供瞬时／静态等价态；
- capability 缺失：WAAPI／IntersectionObserver／`@property` 缺失时退回 CSS class 过渡或静态终态，功能与状态语义不损失（延续既有 capability 检测模式）；
- 键盘等价：所有可触发动效均有键盘路径（Enter／Space／方向键），2px coral 焦点环保留，焦点不因动效丢失；
- 触控目标 ≥44px（既有口径）不因动效缩小；
- 动效不承担唯一状态语义：每项都有非动画冗余（底色／凹陷／文字色／aria），动效关闭时状态依然完整可读。

## 4. 验收口径

- **机器断言**（本地 `output/` 脚本，不入库，延续既有七套回归惯例）逐项：
  - 按压回弹：`getAnimations()` 实证过冲路径（关键帧含 `scale>1` 中间态）；
  - 弹性开关：滑块位移为运行中的 spring 过渡（延续复选框套件 C8t 口径），形变段 `scaleX>1` 且阴影 token 未变；
  - 水波：ripple 原点＝指针落点（±1px），半径覆盖最远角；
  - 爆散：粒子数＝档位表值；失败态零粒子；
  - 勾选：`stroke-dashoffset` 过渡存在且时长 280ms；
  - 液态：三条动画 `startTime`／`duration`／`easing` 一致（或 `--v` 单过渡）；
  - 数字：各位时长呈位序递增、easing 为强减速曲线；
  - 骨架：同型两态高度差 ≤1px，替换帧相邻元素 `boundingTop` 不变；
  - 翻面：两面 `backface-visibility:hidden`（computed），半程只一面可见；
  - 汉堡：单 SVG 三线形变（无第二图标节点），按钮自身 computed transform 为 none；
  - 堆叠：抽走过程中后卡 `boundingTop` 连续可见（采样断言），无跳变帧。
- **视觉复核**：关键态截图（`v11-motion-*`）原像素复核，动效中段与终态各一张；
- **reduced-motion**：全量压制复跑，确认 11 项均瞬时／静态；
- **既有回归保持**：新拟态 80／修复 45／导航 17／复选框 25／动效 12／试戴 14／间距 30 七套合计 223 项保持全绿，动效套件按本方案扩充断言；
- **性能**：动效仅用 `transform`／`opacity`（勾选加 `stroke-dashoffset`，数字模糊可选）；单交互同时活动动画 ≤6；长列表动效分批（IntersectionObserver 既有模式）。
