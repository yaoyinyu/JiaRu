## 正样本识别质量门 schema v2 加权模式（v1.1.532）

- `model/training/build-positive-recognition-quality-report.py` 新增两种门模式：
  - `--gate-mode weighted`（默认，schema v2）：结构门全保留（召回≥0.90、完整mask≥0.85、缺甲图率≤0.10、每图有输出），三个零缺陷门替换为严重度加权伪实例率门 `(1.0×重复 + 1.5×无效 + 2.0×额外)/真值数 ≤ --max-weighted-spurious-rate`（默认 0.02）。权重常量在脚本顶部 `SPURIOUS_WEIGHTS`。
  - `--gate-mode zero-defect`（schema v1）：完整复刻旧八门语义，仅用于 `--verify-report` 重放历史报告；verify 按报告 `schemaVersion` 自动分派模式。
- 修改动机：v1 门容忍 6.3% 漏检的同时要求重复/额外/无效全为零，在有限样本上自相矛盾，导致候选一律否决、无法判定进步方向。
- 兼容性关键点：该脚本唯一调用方是其测试文件；v1 模式输出结构与旧版逐键一致（含 contract 的 `zeroDuplicates/zeroFalsePositives: True`），历史报告重放不受影响。candidate21 的 13/18/17 在 v2 口径下加权率 0.1345，HOLD 结论两种口径一致。
